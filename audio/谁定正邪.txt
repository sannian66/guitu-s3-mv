# 《鬼屠》片头主题曲：《谁定正邪》

**【第一段】**
```
长夜压在我刀锋之上
五百重甲拦不住一道寒光
谁在高处定对错罪状
谁把人命装进天平里称量

我杀过恶徒也放过混账
每一次拔刀都是我的主张
若正义由权势执掌
那我宁愿做乱世的锋芒
```

**【Pre-Chorus】**
```
谁配写生死簿谁配画善恶框
谁的规矩用血来装潢
我不信天不信命不信谁的理所应当
只信这柄刀还滚烫
```

**【副歌】**
```
血未冷 刀不放
谁人来定正邪一方
若规则是铁壁铜墙
那就劈开它看个天亮

血未冷 骨未凉
是非对错我自己扛
天不判 我来量
这一刀就是我的回答
```

**【第二段】**
```
世人教我顾全大局退让
可大局背后是谁的权柄在嚣张
牺牲多少才算够分量
被牺牲的人可曾有机会反抗

不听天命不问上苍
谁的命都握在自己手掌
若这世道黑白颠倒
那就用刀锋重新划出方向
```

**【Pre-Chorus】**
```
谁定好规则谁写好剧本提纲
谁的正义成了交易的暗箱
我不低头不认命不信什么大局为上
信这柄刀还在发烫
```

**【副歌·高潮】**
```
血未冷 刀不放
谁人来定正邪一方
若规则是铁壁铜墙
那就劈开它看个天亮

血未冷 骨未凉

```

**【Bridge】**
```
什么叫大局什么叫牺牲什么叫忍让
什么叫以一人换千人理所应当
若正义由你定义谁来定义你的罪状
谁又来为被牺牲的陪葬

从今往后我的刀只听我主张
谁定的规矩我偏要闯
天不判我来判
刀不答我来答
```

**【副歌·终章】**
```
血未冷 刀不放
世间从来没有什么天理昭彰
若规则是谎言伪装
那就撕碎它自己定规章

血未冷 骨未凉
对就是对错就是错何须伪装
天不判 我来量
这一刀就是我的正道沧桑
```
