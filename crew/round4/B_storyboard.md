# B 组分镜 · 预副歌一（44.048–59.47s）+ 间奏/主歌二（86.19–117.795s）

> 第四轮 · B 组摄制组长。代码：`units/sec_b_pre1.py`、`units/sec_b_verse2.py`，公共件 `units/b_kit.py`。
> 卡点：`crew/round4/B_hitmap_pre1.json` / `B_hitmap_verse2.json`（129.2 BPM，拍长 0.4644s；86.192 为小节头）。
> 切点 = 拍点或人声字头的最近帧再提前 1 帧（与副歌一同一「视觉帧」规则）。

## 0. 总思路：为什么推翻 v2 的 7+14 镜
用户原话：节奏慢、画面简单、重复多、不精致、分镜没设计感、没转场、歌词排版简单。评审基线：预副歌一 64、主歌二 62；
S026/S027「矢量巨刀」、S048「山顶矢量剪影」不可交付；主歌 2.3s 等长切不卡拍；歌词退化成底部白字。

1. **重切**：预副歌一 7 镜 → 14 镜（平均 1.07s，预副歌是冲刺段）；间奏+主歌二 14 镜 → 25 镜（平均 1.26s）。
   所有切点落拍 / 字头，切点疏密跟着乐句走（乐句头密、乐句尾留半拍呼吸），不再等长。
2. **零矢量占位**：一切「刀」都用生图里的真实刀身（从 `slash_h` 精灵里裁出的刀身贴图 + 代码烧红/热浪/火星），
   远景不用多边形山，改成体积雾 + 纹理墙；人物全部是 RH_image2 精灵（统一调色、冷色轮廓光、光包裹）。
3. **字即物体**：每一镜歌词都和画面发生关系（写在生死簿上、框起来、刻进砖缝、被血冲开、铅字被刀尖挑飞、烧在刀上、
   落进秤盘、随雨晕开、宋体烧成行书、随世界倒转、沿刀痕铺向远方）。全句始终可读，不压脸、不出 2.39 有效区。
4. **字体即立场**（全片规则）：权力的话（生死簿、规矩、理所应当、大局、权柄、牺牲、分量、上苍）= 思源宋，铅字/官文/金；
   鬼屠的话（我不信、只信这柄刀、反抗、握在自己手掌、划出方向）= 马善政/志莽行书/流江毛草，朱红。
5. **母题递进**：纸（生死簿→纸人→纸屏风）、框（善恶框→规矩匾→天平秤盘）、红线（朱笔→血沟→刀痕「方向」）。

## 3. 接缝
- **入口 44.048（A 组 → P01）**：P01 开头 0.2s 是墨从黑中洇开成纸面（ink_bleed，墨色从中心向外），任何 A 组末帧（暗底）都能接；首帧主体亮度很低，不会跳。
- **出口 59.30–59.47（P14 → 副歌一）**：P14 最后 0.17s（59.13 军鼓滚奏末击后）定格压暗憋住，刀身横线位于画面 y≈700，与副歌一 S028 刀身横线同高同向；
  59.30（帧 1779）起直接调用 `chorus1.Chorus1().frame()` 输出副歌一的 S028 前 5 帧，所以 1784 帧的接缝与副歌一自身完全一致（不再有两套画风相接）。
- **入口 86.19（副歌一 → V01）**：副歌一在 2584–2585 帧已切到它的 S047（朱墨爆后墨退）。V01 复刻同一墨退遮罩（`K.ink_blot(0.93+0.07*eout(…), seed=47, center=(960,600), reverse=True)`，同一起点时间 86.133），
  墨下的画面换成 B 组的真实刀身/雨夜，2586 帧画面被墨遮 93% 以上，接缝无跳变；画风（冷灰 + 朱、颗粒、暗角、黑边、`c1kit.finish`）与副歌一同一套收尾。
- **出口 117.795（V25 → C 组预副歌二）**：V25 末拍（117.33→117.79）推进 + 压暗到约 30%，刀痕红线留在画面中线，C 组无论从哪种画面进都能硬切接上。

## 4. 统计
