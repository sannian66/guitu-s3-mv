## 各项理由

**节奏卡点 11/15**
- 好的地方：副歌部分（E01–E28，约 31s，28 镜）平均每镜约 1.1s，中间插了 0.47–0.5s 的短促镜（E15 / E18 / E23），疏密有变化。歌词字都随镜头落下，没看到字和画面脱节。尾奏放到 2.2–2.7s 一镜，能收得住。
- 问题：副歌最后的高潮（E25–E28，f6570–6740）反而慢下来了。E25 1.37s、E26 0.93s、E27 1.83s，E27 就是一个人背对日落慢慢走，放在副歌最后一句的推力上，节奏是往下掉的。E02/E03（共 2.9s）连着两个没有动作的大景，第一句刚炸开紧接着就泄了气。逐帧差值看，E03、E27、E33 帧间几乎只有慢推和云在飘（相隔约 1s 的两帧平均像素差约 14），镜头里面没有能卡在拍子上的动作点。

**分镜设计 10/15**
- 好的地方：E04 牌匾、E05 3D 斜切大字、E16/E17/E18 的分屏拼版加裂纹、E20 字放进日轮、E24 握刀特写配红字、E12 俯拍印章，这几个是真正有设计的镜头。
- 问题：构图母题严重重复，基本是「人物居中做剪影 + 地平线 + 背后太阳」。E02、E14T、E22、E25、E26、E27、E34 都是这个结构，一共 7 次。还有「只有云和太阳的空镜 + 字」：E03、E29、E33、E34（加上 E30 片名底板），一共 4–5 次。另外缺少纵深和前景遮挡，几乎所有镜头都是平面正面，没有低机位仰拍，也没有前景虚化的刀或衣角穿过画面。副歌一有书墙、法条纸、月轮几种完全不同的空间，E 段只有一种「金色天空」。

**精致度 9/15**
- E08（S117）中间是一大块过曝的白，主体完全看不见，只剩一圈火边。
- E06/E07（S115/S116）的悬挂卷轴被拉成沙漏形、上下弯曲，看起来像贴图变形的渲染事故，不像是有意的造型。
- E03、E29、E33、E34 的云景底板很糊，没有层次、没有细节，属于素材级的质感。
- E10（S119）人物就是一块纯黑剪影，四周的橙色三角碎片像 PPT 粒子。
- E12（S120b）俯拍小人贴在红印上，边缘和光影都不融，还多出一个圆形的不明物（像是刀镡或扇子叠在一起）。
- 对比之下，E13/E16/E19/E23 的人像和 E24/E35 的手部质量都不错，说明能做到，只是不均匀。

**歌词排版 11/15**
- 亮点：E04「天理昭彰」金框牌匾、E05 3D 斜切、E18 「错」被闪电劈开、E20「天」放进日轮、E24「刀」红字压在刀身上、E26「正道沧桑」大字距排开、E30 片名加印章。这几处达到商业水准。
- 问题：
  1. E03（S113）「从/没/来/世/间」散落在画面上，出现顺序（先出右上的「世」）和阅读顺序冲突，看不出是什么意思。
  2. 小字竖排角标太多、太小，而且做法不统一：E02「刀不」、E06「若」、E19「何须伪」、E22「我来量」、E23「这一」，在成片里大多读不出来，像是遗漏的字幕。
  3. E21（S127）的「判」是红色衬线，「我」是灰白发虚的字，两种做法放在一起像没做完。
  4. E07「谎言」、E08「伪装」是红字压在高亮背景上，对比度不够，而且字号小。
  5. E25（S130）「正」是半透明字叠在人物身上，主体和字互相吃掉。
  6. 「血」在 E01 和 E13 用的是同一种平涂红色方块字，没有材质（副歌一的印章字有拓印肌理，可以对照）。

**不重复 6/10**
- 金色太阳主色调贯穿约 28/36 个镜头。日落剪影构图 7 次，云景空镜 4–5 次。「血」的做法重复（E01 / E13）。whip_pan_blur 转场用了 3 次（E05/E12/E24/E28 前后），白闪 2 次。副歌二之后的听众到这里会觉得「这段一直在看同一个日落」。

**转场 7/10**
- 种类很丰富：paper_tear、shatter、iris_moon、split_slide、slash_wipe、ink_bleed、match_cut、occlusion 都有，E09 撕纸、E19 碎裂、E22 日轮 match cut 都有效。
- 问题：在一个本来就很亮的画面里，zoom_through（E10、E34）、smoke_through（E03、E31）、flash_white（E13、E29）、whip（E28）的中间帧全是一片发白或发糊的金色，看上去和普通淡入淡出没有区别。转场的设计感被底色吃掉了。

**人物 7/10**
- E13 / E16 / E19 / E23 的脸、发丝、眼神都在线，E23 挥刀的动态好。
- 问题：E21（S127）侧脸偏写实西化、头发偏卷，和 E16 / E19 对不上同一个人，有身份漂移。全段有一半人物镜头是剪影或很小的背影（E02/E10/E11/E14T/E22/E25/E26/E27/E34），表演的机会被浪费了。反派（E07 透明老者）只露了一次，而且是虚影。

**情绪叙事 7/10**
- 走向成立：控诉 → 宣言（天理昭彰 / 自己定规章）→ 对与错的对峙 → 片名 → 收刀入鞘 → 一点朱红收尾，尾奏的收法有余味。
- 问题：副歌最后的高潮没有「爆点」。E15 的斩只是一条红线划过纯黑底，没有看到刀砍中任何东西（规条、天、反派），「撕碎」「定」都只停留在字面上。高潮之后紧接着就是慢走（E27），情绪是平的，不是先冲上去再收回来。

## 返工意见（按优先级）

1. **【精致度 / 不可交付】E08、E06、E07 重做**（f5980–6104）。E08 把白芯压到不过曝，让烧穿的纸后面露出主角的半张脸或刀，这样「伪装」被烧开才有内容。E06/E07 的卷轴改回直垂、规整排列，只在 E09 被斩时才变形。E07 的反派实体化，至少给出清晰的五官。「谎言 / 伪装」放大到画面 1/4 宽，加黑描边或背后压暗。
2. **【不重复 / 分镜】拆掉日落剪影母题**。7 次里最多保留 2 次（建议留 E22 横刀、E34 尾奏远景）。E14T、E25、E26、E27 改成：低机位仰拍、前景刀身或衣角虚化入画、俯拍，或者换场景（规条书墙崩塌、夜色转晨光）。同时给 E 段建一个次要色调（冷灰蓝、墨黑红），至少 1/3 的镜头不要用金色天空。
3. **【叙事 / 节奏】在副歌最后一句做一个真正的爆点**（E15 S122b 和 E25–E27，f6295–6740）。E15 的斩要砍中东西（规条墙、「天」字、反派虚影），加 2–3 帧白屏冲击、震屏和碎片飞溅。E27 慢走往后挪到尾奏，或者剪到 1s 以内；高潮的位置换成连续 3–4 个 0.4–0.6s 的动作碎切（握刀 → 出鞘 → 斩 → 字裂）。
4. **【歌词排版】统一小字系统，修 E03 和 E21**。所有两三字的竖排角标，统一放大到至少能读的大小（成片里字高 ≥ 画面高的 6%），固定一个位置规则（比如一律右侧 1/3 竖排配朱印），不要每镜换。E03 改成按阅读顺序依次落字，或者合成一行。E21 的「判我」用同一套材质（建议都用红色拓印加金描边）。E13 的「血」不要复用 E01 的做法，换成墨溅或滴血的笔触字。E25「正」移开人物，或者让人物挡住半个字作前后层。
5. **【精致度 / 人物】E10、E12、E21 重做，空镜加料**。E10 给剪影加轮廓光和衣纹，碎片换成有厚度的金箔或纸片。E12 俯拍人物重新打光、加投影，去掉圆形叠物，印章字不要被人物挡住。E21 按 E16 的脸重画，锁定同一个角色。E03/E29/E33/E34 的云景底板提高清晰度、加中景元素（飞鸟群已有，可以再加山脊线、旗、残碑），每张至少有一个能看清的视觉焦点。
6. **【转场】亮底上不要再用白色系转场**。zoom_through / smoke / flash_white 在金色画面里会退化成淡入淡出。改成深色系：墨晕吞屏、刀光黑切、印章盖屏。whip_pan 全段控制在 2 次以内。
7. **【节奏】E02→E03 合并或压缩**（f5823–5907，现在一共 2.9s），第一句刚炸开就不能连着两个空镜。建议 E03 删掉，把「从没来世间」并进 E02，或者 E02 结尾加一个持刀下劈的动作。

复评重点：上面 7 个不可交付镜头、日落剪影的次数、E15 爆点、小字统一。
