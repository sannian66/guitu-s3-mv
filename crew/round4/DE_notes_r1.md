## #49 E25「劈开的光挡住主角」→ 压光 + 遮罩（21:19）

- 位置：`E25.render`（S130 低机位终极横斩，218.97–220.33s；用户说的 3m40 = f6600 附近）
- 原因：原实现把切线上那条金光带做成「整幅替换」——`fr*(1-band*0.9) + band*GOLDW*2.2`，band 峰值 1.0 时直接把画面替换成纯金，再叠一层 GOLD，**横贯人物胸腹与脸**。
- 改法（三层）：① 光带宽度 `gap*0.6 → gap*0.42`（收窄 30%）；② 压光 `GOLDW*2.2 → 1.25`、加法项 `GOLD*0.9 → 0.5`；③ **用精灵 alpha 挖掉光带**：`msk = 1 - 0.92*info['A']`，光带与辉光都乘它 → 光从人物两侧喷出，人物身上不出光；另在切线补一道 2px 细锐核心（同样避人物）；切点初帧的暖闪 `*1.3 → *1.18`。
- 证据：`out/cmp_DE49_E25_light.jpg`（同帧 f6602 前后）。躯干区亮度 **mean 0.724 → 0.313**（光不再糊住人），人物脸/刀线完全可读。

## #50 E34「逆光剪影头部看不清」→ 轮廓光 + 分离压暗 + 提亮 8%（21:26）

- 位置：`E34.render`（S136 ELS 日出，234.57–237.3s，用户说的 3m55）
- 原因：人物只有 h≈72px，且**头正好压在日面中心**（头 y≈679、日心 y≈681），边缘光 rim 已过曝饱和，单加 rim 无效（实测头部带 mean 0.9818→0.9820，等于没变）。
- 改法：① `put()` 的 `rim_amt 4.0 → 6.5`、轮廓叠加 `0.35 → 0.52`；② **人物外侧压一圈暗做分离**（`halo = blur(A)*1.75 - A`，`fr *= 1-0.78*halo`）——头终于不再糊进日面；③ 头部（A 顶部 30%）轮廓光再 ×1.9；④ 剪影核心少压 6%（0.82→0.76）+ 填充提亮 8%（0.05→0.054）。
- 证据：`out/cmp_DE50_E34_rim.jpg`（f7080 同帧，x2 裁切）。头部带：**min 0.804 → 0.635**（暗背衬把轮廓顶出来）、**std 0.0424 → 0.0818（+93%）**、mean −2.2%；肩胸带 std +12%。
- 备注：**没改人物尺寸/位置**（用户只要光）。若之后还想更清楚，可以把 `h=80-14u` 提到 `92-16u`（+15%），但那是构图改动，本轮不做。

## #51 E34/E35 尾段「BGM 多记重音」→ 跟鼓点卡点（21:29）

- 位置：`sec_e_final_outro.py` 新增 `OUTRO_HITS / outro_punch()`；`full()` 里的运镜 z 加一项；`SHAKE` 给 E34/E35 补条目。
- 数据：`crew/round4/E_hitmap.json`（HPSS percussive band flux）在 **234.4–239.6s 有 16 颗 ≥0.30 的重音**（kick / kick+snare / snare / hat），原来只用了 `strength>0.5 且 type 含 kick` 的 7 颗，且脉冲只有 1% 缩放 —— 所以「多记的重音」画面上没反应。
