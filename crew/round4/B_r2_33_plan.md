# B 段 · #33「黑 / 白」镜像新设计 — 方案 + 效果图（先给你过一眼，再往下推）

## 一句话
把 V20→V21 那一拍（1m49.5–1m52.3，世界转 180° 并翻负片）里的**所有文字**撤掉，改成一组**常驻**的「黑」「白」：
摆在人物右侧留白处竖排，「白」在世界坐标里先镜像翻转（转 180°），镜头转满 180° 时它正好转正 —— 白在最后「变正」，
黑则倒过来；V21 的负片再把黑白互换，这就是「颠倒」。字的倒影不是另外画的，是**丢进水面镜像里跟人一起生成的**，
所以人和字的倒影同源、同涟漪，两条竖（人 / 字列）× 两条横（水线 / 黑白分界）正好交成「#」。

## 「#」怎么成立（可复核的几何）
| 线 | 位置 |
|---|---|
| 竖 1 · 人的中轴 | x≈790（人物+倒影同轴） |
| 竖 2 · 字列中轴 | x=1435（黑/白+倒影同轴） |
| 横 1 · 黑白分界 | y≈408（黑下沿 / 白上沿） |
| 横 2 · 水线 | y=540（人物与倒影、字与字倒影的分界） |
四个交点 (790,408) (1435,408) (790,540) (1435,540) 就是「#」的四个交叉点 —— 人的倒影与字的倒影都不是另画的，是同一次镜像。
