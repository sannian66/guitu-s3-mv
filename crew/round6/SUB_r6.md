# 第六轮 r6-SUB 字幕风格（2026-11-10 15:28 起）

用户原话（15:28）：「底部的字幕好丑，能做成之前竖版歌词那种风格吗」。
本棒范围：只改共享 `units/subtitle.py`（加 SUB_STYLE 开关）+ 样张；**默认仍为现状（SUB_STYLE=cur）**，等用户选。不动任何 section 文件。

## 旧竖版歌词风格要素（从 #53 改前帧 out/round6/VLYR_*_compare.jpg 与 sec_a V09 / sec_b P03 代码里取）
- 字体：马善政楷 `fonts/MaShanZheng-Regular.ttf`（lib/typo 'kai'，V09/V14/LY2 用）；志莽行书 'xing'（P03「谁配画」散排用）。
- 动画：`typo.brush_glyph` 笔序书写 —— 先铺整字淡墨影（BG 写法，防半笔错读）→ 笔锋前沿湿墨晕开 → 行笔末段飞白拉丝 → 落笔墨点飞溅；逐字按演唱时刻起笔。
- 配色：暖白 (0.96,0.93,0.86) + 墨色晕影 shadow 0.85 σ12 + 微光 0.15；关键字朱红 (0.98,0.22,0.12) + 金描边 2px + 朱红外发光 0.35，且放大。
- 字号节奏：关键字大、虚字小（「长夜 压在我 刀锋」），大小错落、竖列第二列下错半格（「谁把人命 / 装进天平」）。

## 逐条
1. **subtitle.py 加 SUB_STYLE 开关**（`99c7dfa`；代码本体先被 autosync `b6a966c` 收走）。默认 `cur` = 现状，逐像素未变。
   - `ink_h`（别名 `old`）：底部黑边内横排。马善政楷；基础字号 74/68/62（≤10/≤13/≤16 字），关键字 ×1.24 朱红、虚字（之的在了也过是就把被又来为么叫个它都还着…）×0.78；底边对齐 y≈1054，最大字顶 ≈962，全在 960–1080 黑边内。
     逐字时刻取 `align.json` words（56 句全部对齐，按句起点索引，副歌重复句不串）；每字提前 0.1s 起笔、0.32s 写完；句尾 t1+0.25 起 0.3s 墨散（晕开 + 淡出）。
   - `ink_v`：画面右侧竖排，右列 x=1770，>10 字从中间断两列（断点避开虚字），第二列左移 1.35 字宽、下错 0.6 字；字号 ≤92；底部不画。
   - 关键字：自动按优先级「血刀骨命罪杀邪墙锋权扛判答闯伪葬黑撕天」每句最多 2 个，另有 `RED_OVR` 手定 17 句（寒光、罪、命、死框、牺牲、千、反抗、纲、退让、劈…）。
   - 可调：`SUB_INK_FONT=xing` 换志莽行书。
   - 验证：`SUB_STYLE=ink_h tools/rf_sb.sh 61.8` 整片管线渲出的帧与离线叠加逐像素一致（差 0.0）。单帧叠加耗时 ≤0.25s。
2. **样张 `out/round6/SUB_r6_styles.jpg`**（1600×1471）：①现状 ②ink_h ③ink_v × 3 时间点（0:21.3 主歌一「五百重甲拦不住一道寒光」、1:01.8 副歌一「血未冷 刀不放」、2:50.7 Bridge「什么叫以一人换千人理所应当」），①②下附字幕区放大；④ink_h 逐字书写过程 8 格（59.45–62.40s）。
   时间点没用建议的 18.0/61.0/170.0：那三刻都是句子写到一半（18.0 句子还没开始），换成句尾整句都在的帧。底图 SUB_OFF=1 经 cpu_slot 渲（out/r6tmp/sub/，不入库）。
   自评：ink_h 8（书法感、朱红关键字、逐字书写都回来了，黑边内不压画面；小字在 1/4 缩略下略细）；ink_v 8（最像旧竖版，但压画面右侧，和画内横排字如 0:21「拦不住」并存时字多）。
