## 2. 运镜加量（VCam3 2.5D 相机 + MOVES3 表）
- 通道：z 推拉 / x,y 横移·升降 / rot 荷兰角 / **yaw 环绕**（平面绕竖轴转的透视单应，近大远小）/ **pitch 仰俯·摇臂** / **vtg 变焦推拉**（中心主体不变、四周径向拉伸）/ **focus 焦点转移**。
- 透视、滚转露边由 auto-fit 自动补缩放（只看有效区 y120–960，不含甩镜位移，甩镜时不会突然放大）。
- 速度坡度 `beat`：镜内速度 = 底速 0.35 + 每个小节头（1.0）/重音字（0.6）后的指数加速脉冲（τ0.22s），切点本身也给一次加速；镜尾 32%（≤0.55s）刹车到 20% → **重拍上加速、乐句末减速**，节奏感从运镜速度来。
- 运动模糊按位移 + 环绕/仰俯折算速度自动生成；推拉/变焦推拉给径向模糊。
- 前中后景视差：`FGOcc` 前景遮挡物（碎砖 / 芦苇 / 墙角立柱）按 2.0–3.0 倍机位位移移动；非焦点转移镜头里它虚焦（σ16），焦点转移时由实变虚、场景由虚（σ8）变实。

## 4. v3 字幕规范（全片字幕规范，units/lyric3.py；后续各段照此执行）
1. **字体**：歌词一律思源宋 Noto Serif SC（fonts/NotoSerifSC-Regular/Medium/SemiBold/Bold/Black.otf，noto-cjk 官方 SubsetOTF/SC，OFL）。
   整句 **SemiBold**；主字 **Black**；辅助小字 **Regular**；刀上刻字 Bold。马善政/志莽行/流江毛草不用于歌词。
   - 书法主字对比（out/chorus1_v3_mainchar_compare.jpg，上=宋 Black，下=志莽行书；「墙」「天」两处高潮）：宋体 Black 版更好——「墙」像整块刻石、与砖墙浮雕同一语言、重量感更强；「天」在月面上形成干净的日蚀剪影，横画能被刀光斩开得更利落；行书版笔画细碎、在浮雕/剪影处理下发糊，且与整句宋体打架。**结论：本段主字全部用宋体 Black，未使用书法字。**
2. **字号三级**（全段一致）：主字 440px 字号（≈ 有效画面高 840 的 50%）；整句 62px；辅助小字 34px（只用于片尾署名「鬼屠」）。
3. **版位只有两种**：底部三分之一横排居中（字心 y=850，距下黑边 110px）/ 右侧竖排一列（字心 x=1752，首字 y=262，距右边 168px）。
   整句字距：横排 +0.22em，竖排 +0.30em；竖排标点用竖排形（︐︒︑…）。同屏只出现一句；不散落单字；读序 = 演唱顺序。版位按「不压人物脸/刀」逐句选定（下表）。
4. **颜色**：正文暖白 (0.97,0.94,0.88)；每句至多一个朱红关键字（字用朱红 0.84,0.10,0.07）；金 (1.0,0.78,0.42) 只给与光相关的字（「天亮」）。
   描边/投影/辉光统一一套 `STYLE = shadow 0.72 σ20 + 自色辉光 0.20 σ14，无描边`。
5. **入场族「锐光擦入」**：每字在演唱字头前 0.24s 起，沿读向（横排左→右、竖排上→下）遮罩擦入 + 由虚到实（σ5→0）+ 擦入前沿一道细锐白光，**字头视觉帧（−1 帧）恰好落定**。
   **出场族「墨散」**：按读序逐字（间隔 0.03s）噪声溶解 + 微虚 + 上飘 10px，0.26s，在下一句入场前清空。

## 虚拟摄像机（units/vcam.py）
- 底鼓：推近 punch（瞬时跳入、欠阻尼回弹，3.6Hz ζ0.5）+ 随机方向衰减抖动；军鼓：反向轻拉 + 交替方向旋震 + 垂直顿挫；hi-hat：17Hz 细碎抖；重音镲：大 punch + 强抖 + 旋；重音字：额外 punch。全部乘段落能量包络 `ENERGY` 与每镜 `GAIN`；定格段（`hold`）脉冲静音。
- 基础运镜 `MOVES`：每镜缓动曲线（expo/quint/cubic/sine）+ 速度坡度（fsf 快-慢-快 / fs / sf）。
- 甩镜：切前 4 帧加速甩出、切后 5 帧同方向减速甩入，自动按相机速度做方向运动模糊；推拉速度做径向模糊；硬切不跨切点算模糊。
- 前景视差层 `FGLayer`：近镜头虚焦余烬/灰/雨珠，按深度 1.5–3.2 倍相机位移移动。
