## 1. 要做什么
- 本单元负责的**每一镜**都换成风格 D：重新生图、分层，替换旧精灵/旧背景/旧代码画的场景。S028–S030 已通过，冻结不动。
- **文字**：只保留 USER_NOTES 表里点名「保留」的字，其他画面字（叠加的、刻的、写的、装饰的、不可读的）全部去掉。保留的字**画进生图**（RH_image2 能写中文；逐字放大核对字形，错一笔都不能用），代码只做揭开/灌血/烧出等动画，不要描边、投影式的字体层。整句要求的一次做完，不按镜号截断。退路（两次生图都写不对）：生图留空载体，代码按载体透视、材质、光影刻进去，并在 NOTE 里注明。片头署名和片名、片尾署名是合同要求（HANDOFF §1），保留，改成风格 D 配色。底部歌词字幕（`units/subtitle.py`）不动。
- **去字后画面空了**的就重新构图（可以改机位、景别、主体位置），切点和镜长不动。
- **用户点名「重做分镜」/「换个形式」的镜**：可以换镜内内容和动作，切点、镜长、入/出转场、字幕时刻不动；冲击帧落在原来的鼓点上（hitmap / CUT 表 / align.json）。

## 2. 分层与动效（硬要求）
- 每镜至少「背景板 + 主体抠像」，按动效需要加层：前景、云带、多层雾、飘布、发丝、红带、可以单独动的道具、碎片……**层数不设上限，以动效需要为准**。
- **人物不能整张定格平移**（评审：「贴图滑动」）。动作镜至少 2–3 个关键姿势，或者把会动的部件拆层做二级运动（发丝、红带、衣摆飘，呼吸）。
- **视差不能漂**：镜头锁定主体层；各层视差偏移以镜头中点为零；粒子运动也以中点为零；不逐层手调 dy；精灵按包围盒高度落脚（`put()` / `SP.layer().fit()`）。同一个物体（如算盘框和梁）必须是同一个刚体层。
- **现版效果全部还原**：慢放、闪白、甩镜、刀光、星芒、色差、颗粒、震屏、手持晃、火星、余烬、转场……效果密度和卡点精度不低于现版。
- **特效笔触也要风格 D 化**：刀痕/斩痕用干笔飞白 + 溅墨；碎石、碎片用生图抠层或墨线勾边，不用平滑渐变和纯色矢量多边形；雨用细墨线短划、长短粗细有变化；火星用白 + 血红。

## 3. 色板
严格黑 / 白 / 灰 / 血红。`STYLE_D=1` 时 `units/style_d.py` 在出画前兜底（只保红色相，其余去色），所以金、暖橙、冷蓝都会变灰——**不要依赖金色做重点**，改用白光、血红、明暗对比。精灵合成一律 `grade=NEU, rim=NORIM, wrap=0, shade=None`（见 S028D–S030D），不要冷色调色。亮度对标标杆：白纸、网点占大面积，不要整体压暗成一团黑。

## 5. 样镜评审给出的通用扣分点（铺开时不要再犯）
1. 字是代码叠的 / 带斜面高光的「电脑立体字」→ 要墨线刻痕、毛笔字，画进生图。
2. 人物整张平移、残心段发丝红带全静止 → 拆层做二级运动。
3. 刀痕平滑渐变、碎石纯色多边形 → 飞白溅墨、生图碎片。
4. 墙面中灰带棕褐、整体偏暗、网点少 → 去色，加网点，白纸占比对标标杆。
5. 一闪帧剪影糊边、红楔停在头顶像长了角 → 冲击帧用出刀姿势、硬边反白、红线贯穿全画面。
6. 画面里有读不出是什么的红色糊块、刚体之间漂移、雨丝划过字 → 构图重心清楚，出字帧把字周围压暗。

## 10. 第一份评审（B1，78 分不过线）暴露的通用问题（11-11 补，所有单元自查）
1. **整体太暗**：B1 画幅区平均亮度约 45，标杆 S028–030 是 81。目标画幅区（去上下 120px 黑边）平均 ≥65，白纸、网点占大面积；镜头尾的压暗只在最后 6 帧内。交付前用 ffmpeg 抽帧量一下，写进 NOTE。
2. **道具/特效有 CG 感**：带镜面高光的 3D 球体/棋子、景深虚化、平滑矢量冲击圆环、平涂渐变底、光剑式发光刀身、塑料亮面的血 → 一律改成墨线勾边 + 网点、干笔飞白、溅墨、哑光墨红。
3. **人物整张定住**：单一姿势 + 微推 = 不过线。每个人物镜至少有二级运动（发丝/红带/衣摆拆层飘、呼吸），动作镜 2 个以上关键姿势，在字头/鼓点硬切。
4. **相邻镜构图重复、素材复用**（同一种血花、同一片天空连用 4 次）→ 换景别、换素材。
5. **群演/配角画成扁平卡通** → 统一墨线 + 网点。
6. 画进去的字，辉光不要太亮，否则看起来像叠在上面的光层。

## 11. 第二份评审（EB，75 分不过线）补充的通用问题（11-11）
1. **景深虚化**（背景糊掉）一律算 CG → 远景用清晰墨线 + 网点渐隐来做纵深。
2. **写实镜头光斑 / 镜面亮漆** → 墨线星芒、白色硬边闪、哑光墨线勾边。
3. **道具要统一**：鬼屠的刀是直刀 + 中式护手、黑柄、刀鞘红穗（定妆照），不要武士刀刀镡、菱形缠柄或弯鞘。
4. **超过 2 秒的静止卡**（片名卡、空镜）也要拆层做慢视差 / 墨晕呼吸。
5. **背景板跨镜复用**会被抓（连红烬位置都一样）→ 换板或至少换机位、换裁切。
6. **小字署名和小字说明**要放在干净的底上，1080p 下清楚可读。
7. **（用户硬规则，11-11）任何图层都不允许露出裁切边**：精灵、符号、溅墨、碎片等抠像素材的包围盒和画布边界，不能在画面里形成直线或矩形边（用户在 S124 ✓ 笔触上抓到）。素材四周要留足透明边；需要遮挡时用有形状的羽化遮罩，不用直线截断；推镜和位移的每一帧都要检查。
