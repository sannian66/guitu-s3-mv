## 评审通用问题（SPREAD §10 / §11 / §12）自查
1. **亮度**：`Shot.render = paper(draw)`，白纸提亮只抬中间调（网点灰 → 纸白），墨黑（<0.04）和血红（与 style_d.red_mask 同一口径）不动；每镜用 PK 控强度。另外加了三张白纸背景板（sky_paper / sky_red / ground_paper）和一张亮墙（wall_bright），分给不同镜头。实测见下。
2. **CG 感**：景深虚化全部去掉，改成 `haze` 向纸白渐隐（C22 / C29 / C39）；高斯辉光、光斑改成硬边墨线星芒 `star`（C38 / C39 / C40b）；C31 的平滑矢量冲击环改成干墨水浪笔触；C29、C37 前景的焦外剪影改成硬边墨剪影 + 白墨线。
3. **人物二级运动**：所有人物精灵都有风吹（发丝 / 衣摆 / 红带位移场）+ 呼吸；风吹幅度按 §12-3 统一减半、封顶 7px（低幅，避免果冻感）；动作镜两姿势以上、在字头或鼓点硬切：C24（跑 → 急停）、C31（站 → 震飞）、C32（蓄势 → 斩毕）、C34（举刀 → 斜劈，本次新增）、C35 → C35b（同轴跳切）。
4. **相邻镜不复用背景板**：本次新增 5 张图，把背景板拆开；相邻镜之间同一张板一律换机位或镜像（C24 墙镜像、C25 / C26 是同一面墙劈开再崩塌，属于有意连续）。
5. **裁切边（用户硬规则）**：① 背景视窗用 `_view` 夹紧在底板内，任何一帧都不采到底板外；② 原素材贴画布边的精灵（CB_point / sash / bracecu / walkfront / windup / knock / grip / feet / final / lookup / balance）调整位置和大小，让贴边那一侧始终在画幅外；③ 兜底：贴边一侧乘不规则羽化（`feathered`）；④ C39 天平底座沉进起伏的雾线（形状遮罩，不是直线截断）；⑤ C26 贴画幅边的碎块不飞走；⑥ C23 墙石四周留透明边，石窝 / 投影按石块轮廓。自检：`CB_EDGECHK=1` 时逐帧把原素材贴边段（含 70px 羽化带）变换到屏幕上检查（`out/r8/CB/scripts/edgescan.py` 只算几何、逐帧跑完 620 帧）：原素材画布直边本身落进画幅区的只有 C39 天平底座（已由起伏雾线遮罩淡出）；其余命中都只是羽化带（≤70 源像素）伸进画面，画面上是渐隐、不是直线：C22 墙脚小人的脚底（没入积水）、C31 被震飞时的刀尖、C29 头顶发梢、C35b 两袖口、C38 刀身出画右侧、C41 衣摆下缘。
6. **刀**：鬼屠的刀全部来自带定妆照参考的生图（直刀、黑柄）。自查 §11-3 时发现 C38 的握刀手特写（CB_grip）刀柄是菱形缠柄（tsuka-ito）、护手是雕花金属鍔，11-12 以原图图生图重出：素黑布缠柄、素面铁圆盘护手、柄头红穗，构图 / 手 / 护腕 / 刀身 / 水珠不变（`CB_grip2`）。其余镜整身尺度下刀身都是直刀 + 中式护手 + 黑柄。
7. **定妆照**：鬼屠的镜都带定妆照参考；太上皇出镜（C31 的手）这次改成带太上皇定妆照参考重出（CB_hand2：枯瘦人手、黑纱宽袖，不是爪）。
8. **小字**：本段没有画面小字；保留的只有匾字（大字）和底部字幕。
9. **§12-1 连续动作图生图**：同一镜里硬切的两张关键姿势改成以第一张为底图、用 nano-banana-pro 图生图衍生第二张：C24（跑 → 急停）、C32（蓄势 → 横扫斩毕）、C34（蓄势 → 跪地斜劈），共 3 张。C31（站定 → 被震飞）仍是两张独立生图（预算已超，没再出）。
10. **§12-2 天空 / 云流动**：天空和地面板的天空部分不再是「一张图平移 / 缩放」。`advect()` 按空间变化的流场推云：大尺度旋度噪声 + 主风向（每块云按所在位置各走各的方向）+ 一层随时间缓慢翻涌的湍流；地平线以下（积水、地面）不动，底板边 70px 内位移归零（不出镜像接缝）。时间以镜头中点为零。C22 / C26 / C30–C35b / C37–C41 共 19 处背景调用都接上了（CB_gap_els 上半是墙，没加）。
11. **§12-4/5 接地**：C22 墙脚小人和 C31 / C35 的人都落在背景板的地面线上（按包围盒落脚，C22 加了接地阴影）；C36 跪伏千军是一张整图，地平线统一。
