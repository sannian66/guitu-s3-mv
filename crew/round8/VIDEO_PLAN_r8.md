# 第八轮 · 视频生成方案评估与分配（2026-11-11 20:30）

用户决定：「还是生视频会更好一些……你自己去评估哪些片段需要换成视频生成方案。然后优化一下即可。」
成片规格（用户同日确定）：**2K 2560×1440、24fps**，2.39 画幅上下黑边各 184px。视频生成的片段本身就按这个出，不降分辨率不重排帧率。

**代码管线的分辨率/帧率不改**（用户 11-11 20:5x：「不用了，如果那么麻烦的话，就不改了」）。原因：分辨率写死在 20 多个 kit 文件里、960/540 中心坐标 650 多处、字号 110 处；帧率改动会让 CUT_F/鼓点帧号全部重算。做法：代码仍按 1920×1080 / 30fps 渲染，出片时统一用 `tools/export_2k.py` 升采样到 2560×1440、按时间重采样到 24fps；视频生成段是原生 2560×1440 / 24fps，出片时直通不转。墨线 + 网点的画面升采样损失很小。

工具：`tools/vidgen.py`（MiniMax H3 特价版 `minimax-h3-metaso`，模式 `image2video_first`，2K 16:9，4 秒，**12 积分/次**；生成后自动补黑边 + 过 `style_d.palette` 色板兜底）。审核接口当前 401，但该模型参考图审核要求是 never，直接提交即可。

## 一、试做结论（**2026-11-12 按四份试做报告修订**，上一版的判断有错）

> 上一版（11-11 20:30）这张表把「走路远景」判成「适合」，依据只是看过一遍的直觉。四份试做的逐帧报告出来后，**这个判断是错的**，已订正。修订前不要按旧表分配积分。

| 试做 | 报告原文要点 | 判定 |
|---|---|---|
| **发丝/衣摆飘动**（人物近景只有风在动） | 「发丝……一缕缕分开、方向一致地扫动」「全片 0 个非红色相像素」（色板守得住）。但同一条报告也说「脸型、瞳孔、眉线三帧几乎不动」——风动了，**表演没动** | **有条件适合**：可以解决「发丝红带全静止」，但不能解决「人物定格」。用它的镜必须本来就只需要风 |
| **走路远景**（人物走远） | 「画风和构图可用，但『走路』这个核心动作没做出来，太阳放大也破了设定；作对比样片可以，**直接进成片不行**」 | **不适合**。走路仍用 **nano-banana-pro 图生图衍生连续关键帧**（SPREAD §12-1，EB 段已按此法做实并验收：头肩质心逐帧位移单调，不再来回跳） |
| **三连击**（快速动作） | 「第 3 斩之后刀身被画成一条纯白发光管」「所谓『三连斩』实际只有原地小幅上下挥动」 | **不适合**。快速劈斩继续用代码刀光 + 生图关键姿势按拍硬切 |
| **天空漩涡（云流动）** | 「画风守不住……云带的干笔飞白被抹成灰色雾块……亮度掉了 25%」 | **不适合**。云/漩涡用代码流场位移 + 多层云板交替（SPREAD §12-2） |
| **E34 整帧版**（山水 + 人物一起生成） | 画面自然，人物轮廓与服装有轻微漂移；EB 段据此做了走路镜 | **有条件**：只用于远景剪影、全景，且该镜本来就不需要身体动作 |

**结论：视频生成的价值比上一版估计的小得多。**它真正稳的只剩「近景、只需要风」这一种；而这一类恰好是代码最好补的（拆发丝/红带/衣摆层做二级运动）。

## 二、现在的做法：**先冻结视频生成，返工全部落地后再做一次定点复核**

1. **本轮全部单元先不做视频生成**（协调者已逐个通知）。返工、渲染、PR 都完成后再统一决定。
2. 复核方式改成**定点、少量、拿当前版本的渲帧做首帧**：每类先做 1 条，看完再决定要不要铺开。上一轮是拿旧帧/合成帧做的，结论不能直接外推。
3. 复核清单（按价值排序，每类 1 条，共 4 条 = 48 积分）：
   - 近景风动（选一条本来就只需要风的镜）
   - 群像连续动作（叩首波浪 / 人海涌动）
   - 雾·烟·水的持续流动
   - 远景人物 + 背景一起动（E34 型）
4. 走路/跑/跳/落地这类**位移连续动作**一律走 nano-banana-pro 图生图衍生关键帧，不走视频生成。

**明确不换（保持代码/生图）**：快速劈斩与三连击、天空漩涡等图形化动效、任何带合同文字/署名/片名/匾额的镜头、0.5 秒以内的碎切、远景走路。

## 三、批量使用的做法

- **一条 4 秒片段覆盖同场景连续 2–3 镜**：取该组第一镜的首帧生成，成片里按原切点截取需要的 1–2 秒段落，剩余部分弃用。这样 12 积分覆盖 3–5 秒成片。
- 首帧必须是**当前版本**的渲帧（和该单元同一套素材/调色），否则会跳。
- 提示词写「镜头固定、不摇不切」；需要运镜时由代码在成片上再做一次 2.5D 推拉，不要让模型自己摇。
- 生成结果入库放 `assets/gen/R8_D/vid/<单元>/<镜号>.mp4`（用 `git add -f`），`out/` 不放。
- 每段记 `crew/round8/genlog_<单元>.md`，注明「视频生成」。
