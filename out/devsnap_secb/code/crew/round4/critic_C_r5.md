## 逐项理由

### 1. 节奏卡点 13.5/15（±0）
- 平均镜长约 1.0s，高潮段 C33 0.47s、C40 0.47s、C40b 0.43s，速度拉得起来。
- 扣分（与 r4 相同，未改）：
  - C05（123.20s，0.90s）箱子居中正面，只有钱币粒子在动。
  - C21/C22/C23/C24 四个镜头 1.37–1.40s 连排（139.93–145.5s），副歌中段明显拖慢。
  - C13 1.37s 的风眼也只是一个居中物体在缓推。

### 2. 分镜设计 12.5/15（+0.5）
- 加分：C32 改为低机位中景，C31（全身侧仰）→C32（中景仰拍）→C33（刀刃特写）的景别递进变清楚了。
- 扣分：
  - C05、C13、C37 仍是「居中正面单物体」构图，缺前景层。
  - C04 左秤盘上方飘着一团彩色碎纸人（f3678 左上），没有交代来源，读起来像五彩纸屑，打散了视线。

### 3. 精致度 13/15（+0.5）
- 加分：C03 人偶有了服饰和关节；C41 去掉了蚂蚁线。
- 仍然掉档：
  - **C03**：模板克隆、正面受光、不透色，和后面写实的雨夜不是一个材质体系。
  - **C04/C05**：关键字红青错位。
  - **C13** 风眼、**C15** 闪电贴片、**C19** 等大枪头、**C26** 三角碎片：四镜都没动，仍是全段的 CG 短板。
  - **C41**：字芯过曝成纯白黄（f4830），火焰外形把竹字头吃掉一部分。

### 4. 歌词排版 13/15（+0.5）
- 加分：C41 阅读顺序修好；C04/C05 字的位置进入视线中心。
- 扣分：
  - C04/C05 仍是细宋体加打字机光标，在全段最「权力」的一句（谁的正义 / 成了交易的）上最没有设计。
  - C21「一方」读不出来。
  - C16「血」贴遮幅边。
  - C40（159.63s）右上「刀就」在「这一」还没唱完时就以半透明灰的「就」提前出现，和「这一」叠成两组字，有点乱。

### 5. 不重复 8.5/10（+0.5）
- 加分：C09/C32 拉开了景别和机位。
- 遗留：
  - C09、C31、C32 三镜都是「举刀 / 后仰 + 雨夜灰底」。
  - 「血 未冷」在 C16（135s）和 C30（149.8s）各出现一次。歌词重复可以接受，处理方式也不同，但两处「血」都是朱红块字，可以再拉开一点。
  - C03 一排克隆人偶本身就是镜内重复。

### 6. 转场 9.5/10（+0.5）
- 加分：C26→C27 smoke_through、C27→C28 flash_white，两处中间帧都干净了。转场种类在 14 种以上。
- 扣分：C21→C22、C28→C29、C38→C39 三处 hard 的冲击帧都是近乎全黑的暗角压场，没有闪、抖或色偏，冲击力弱。

### 7. 人物 8.5/10（±0）
- 主角定妆统一（C07/C08/C28/C29/C32/C35b/C39/C40b/C41），对立者 C20/C21 也统一。
- 扣分：
  - C41 的人物仍比 C35b 更「插画」：发丝高光强、脸偏嫩。
  - C15、C22、C27 人物过小，C15 的雷光仍没有勾出主角。

### 8. 情绪叙事 9.5/10（±0）
- 叙事链完整：剧本 → 提线 → 秤 → 暗箱 → 不认 → 赤刀 → 风眼 → 血雨 → 冲锋 → 定 → 邪正 → 铜墙 → 劈开 → 天光 → 扛 → 跪军 → 判 → 量 → 斩秤 → 刀就是我 → 答。
- 扣 0.5：C13 风眼入口仍偏卡通，「风暴之眼」这一幕的门面不够。

## 返工清单（已过线，以下是冲「获奖级」的建议）

### P0
无。

### P1
1. **C04/C05 关键字（122.07–124.1s）**：「正义」「交易」的红青错位二选一。
   - 要么去掉错位，换成朱红实色字加金属冲压凹痕。
   - 要么把它做成有意的 2–3 帧故障抖动，在落字那一拍闪一下就回正，不能整镜挂着。

   同时，整句「谁的正义 / 成了交易的」改成粗铅字或铸字质感，字高提到 110px 以上（1080p），去掉打字机光标。光标在古装片里出戏。
2. **C03 人偶（120.93s）**：
   - 改成背光皮影：后方暖光透过人偶，袍面呈半透明彩色，袍上镂出雕花透光。
   - 每个人偶的姿势、提线角度和摆动相位都错开，不要一排克隆。
   - 「纲」加纸刻或墨刻质感。
3. **C13 风眼（131.67s，1.37s）**：这是叙事入口，要加体积云层，做出前中后三层旋臂、云层自转和纵深推进。黑球边缘要有被吸入的雨线和碎云，不要用平面速度线。也可以考虑把镜长压到 0.9–1.0s。

### P2
4. C41「答」的字芯压回暖红，外缘保留焦黑，竹字头的笔画要完整可读。火焰只做在边缘，不要整字过曝。
5. C26 中帧（146.10s）把碎片改成不规则石块，带砖纹，延续 C25→C26 冲击帧的碎片形态。
6. C19 枪头加透视缩放，近处加虚化；C15 让雷光勾出主角轮廓。
7. C21「一方」放大、提亮，或者刻进分屏线上；C16「血」上移，离开遮幅边。
8. C21→C22、C28→C29、C38→C39 三处 hard 加冲击手段：白闪 1 帧、抖动或红偏，不要用全黑暗角压场。
9. C21–C24 连续 4 个约 1.4s 的镜头，至少拆短或加切其中一个，避免副歌中段掉速。
10. C40 去掉提前出现的半透明「就」，让「这一」→「刀就是我」干净交接。
11. C04 左上的彩色碎纸人要么交代来源（从秤盘倾落），要么删掉。
12. C37「判」匾加前景（雨帘、匾框近景虚化），把匾心金字提亮。
