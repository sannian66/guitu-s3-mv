# 评审 · D 段（Bridge，帧 4839–5797，161.3–193.2s）· 第二轮

> 评审依据：out/round4/D_contact_v4.jpg、out/round4/D_keys_v3.jpg、CHARTER「硬性质量要求」「评审」两节。另外自己单帧渲染了约 105 帧核查：每镜取入点+2 帧、中点、出点−3 帧，并补渲了转场中间帧和疑点帧。标杆是副歌一，渲了 64.2s、73.5s、82.8s 三帧。没有读分镜、HANDOFF、代码注释和上一轮评审的内容。

## 总评

**81 / 100，不过线。** 每项都在 70% 以上，差在总分不到 85，另有 1 个不可交付镜头（S08 尾段）。

这一版的整体水准已经明显高于副歌一标杆：30 镜，平均 1.06s。叙事是白纸审判庭 → 火烧 → 余烬睁眼 → 拔刀 → 撞墙 → 风暴之眼 → 判 → 金色「答」，弧线完整，前后两半色彩反差也做出来了。

扣分集中在三块：
1. 后半段歌词排版退化成「大号白色宋体 + 人物」的通用模板。「我」字用同一种版式出现了 3 次。
2. 字砖、字卡母题用得过多，S20 还和副歌一撞了画面。
3. 几处精度问题：S08 印章糊团；S29 柱上的字倒置、镜像；S18、S29 两个转场的中间帧有穿帮。

## 返工意见（按优先级）

**P0（不修不过线）**
1. S08「当」印：最后一方「当」要整方压在最上层，字形完整、朱红实底、白字清晰，至少完整停 8 帧再转出。去掉中央那团黑墨，或者把黑墨挪到印外做溅点。
2. 总分差 4 分，从下面的 P1 里挑排版和不重复两项修，最划算。

**P1**
3. 后半段排版重做「他的字」系统：S21、S25、S28、S29 不能再用「白色粗宋叠在左侧」。三个「我」各给一种和画面互动的处理，例如 S21「我」被字卡撞碎后拼出来，S25「我」刻在长枪的刀光轨迹上，S28「我」随定格残影分层错位。S29「来」可以刻进被刺穿的碑柱，或者被金光从柱里炸出来。
4. S20 去掉和副歌一撞车的「砖墙 + 小人背影」：换成俯拍字墙地面、人物踏字前冲，或者墙面贴脸前景遮挡。同屏只留一组「规矩」。
5. S29 碑柱刻字改正向可读，或者明确做成倒影并加水面质感；split_slide 换成有画面动机的转场，例如刀尖金光纵向劈开。
6. S18 slash_wipe 的字层只放在一侧，别让上下两半同时带字，消除叠字；同时把 S18 换掉 T 字站姿，改成侧身半抽刀或刀尖指地，配合「只听」。
7. S11 人物和 S16/S17 统一成同一张脸（发型、脸型），或者把 S11 换成同一精灵的举刀图。

**P2**
8. S01 黑场缩到 ≤0.3s，红点早落，或者让涟漪更早出现。
9. S10 给巨人加运动：袍角、锁链晃动、缓推，避免 0.7s 静帧。
10. S22「闯」初始位置让开脸部（放在身前低位或侧边），撞碎时再穿过人物。
11. S24 中点的粉紫色偏要么去掉，要么做成有动机的雷光色。

**P3**
12. S09 入点 ink_bleed 的 mask 提高分辨率或做羽化，去掉块状像素边。
13. S30 入点「答」的金色加暗部层次，避免整屏灰黄发闷。
14. S27「不答」放大到约「刀」字的 60%，或者错位排列加强句读。
