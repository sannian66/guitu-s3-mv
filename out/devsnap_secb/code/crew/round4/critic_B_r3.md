## 逐项理由

### 1. 节奏卡点 13/15
- ✔ 切点仍然都落在拍点上。两段的平均镜头时长都远低于规定的上限。V13 的「可」（100.62）入画准确，V16「苍」现在停留足够。
- ✘ **V02（f2629–2679，约 1.7s）基本是静止的。** 起、中、止三帧里，只有雨在动，人海整体没有位移、起伏或推近，静止明显超过 1 拍。（-1）
- ✘ **V01 钟楼（f2586–2623）镜内运动很弱。** 钟不摆、不震，只有极慢的推近加雨。这是主歌二的第一镜，钟声的意象却没有被「敲响」。V06 反派 CU（f2803–2816）也近乎定格，只有字在出。（-1）

### 2. 分镜设计 12/15
- ✔ V14 跪群中站起、V16 石碑仰拍斩碑、V20 水面倒影分屏 → V21 整画翻转「黑白颠倒」、V09 / V10 算盘梁特写，主歌二的设计感比上轮明显提高。图形匹配仍然 ≥3 处。
- ✘ **V07 → V08 仍然撞构图**：两镜都是竖直的杆状物居中偏右，手从画框下方伸入握住，加金字，景别和方向一样，连着 1.5s。
- ✘ **V12「被牺牲的人」仍然是全段最弱的一镜**：人物漂在没有空间的灰底上，「被牺牲」没有施加者、没有地面、没有代价。
- ✘ V01 → V02 两镜都没有歌词，也没有主角，都是大景空镜，加起来 3.3s。作为主歌二的开场太松，主角到 V13 才第一次清楚地出现。

### 3. 精致度 10/15
- ✔ 导歌一保持商业级质感。主歌二的 V11 秤杆（麻绳、铜星、雨痕）、V16 石碑、V24 / V25 朱红轮廓光和地面红裂线，都明显升级了。
- ✘ **V18 拳头（107.6–108.1s，ECU）是畸形手**：四指融成一块，没有指缝，没有指节，像泥塑或者烧化的蜡。这一镜还是放大镜头，压在「握在自己」的关键词上。**不可交付。**
- ✘ **V08 握柄的手（f2837–2880，约 1.4s）是两个没有分指的灰色肉团**，绕在刀柄上，看不出是手。背景纯黑，也没有雨，和前后的雨夜断层。**不可交付。**
- ✘ **V02 人海**：同一个跪姿精灵复制几百遍，排成规则网格，比上轮的 V03 / V04 阵列更廉价，属于游戏引擎批量实例的观感。
- ✘ **V01 调色断层**：全段只有这一镜是饱和的冷蓝，而且开头 f2586–2595 左侧有一块形状不规则的暗红色团，像脏点，不像设计过的血溅。
- ✘ V08 金字辉光，加 V10 结尾 f2925 的 RGB 撕裂残影，仍然是模板化特效，和水墨、金属的整体质感不统一。

### 4. 歌词排版 12/15
- ✔ 导歌一保持高水准。主歌二新增了几处字和画面的好互动：笏板「大局」、算盘梁「牺牲多少人」逐珠亮起、秤杆刻度「分量」、石碑「上苍」被劈、V14「反抗」燃烧、V21「黑白颠倒」随画面倒转、V22–V25「出新方向」被刀光划出。
- ✘ **粗宋金字加辉光仍有 7 处**：V03、V07（橙）、V08、V10、V11、V15、V16。其中 V03「顾全」、V08「嚣张」、V15「天命」仍然漂浮在画面上，没有和任何东西互动。
- ✘ **一句歌词混用字体（上轮 P1 没改）**：V16 一个画面三种字体，V15、V08 也是两套字体并存，看着没有字级规矩。
- ✘ **V18「握」的行书读成「搖」**。这是关键词，而且意思正好相反。V12「的人」偏弱。

### 5. 不重复 7/10（压线）

- ✘ **段内「手握杆状物」的特写出现 4 次**：P14、V07、V08、V18，而且后三次都在主歌二 13 秒之内。
- 提醒（不扣分）：P10 / P11 铅字盘「满墙汉字网格」和副歌一 S036 字砖墙视觉上接近，总导演连播时请看一下。

## 不可交付镜头
1. **V18（≈107.5–108.4s，「握在自己」）**：ECU 拳头畸形，四指粘连，没有指节。必须重做手部，或者换成实拍质感的手部素材，或者改用剪影或侧逆光，把手的结构藏在暗部。
2. **V08（f2837–2880，「柄在嚣张」）**：握柄的手是两个没有分指的肉团。必须重做；或者干脆不出手，只拍刀柄，让「嚣张」由别的动作带出。
