## 0 一句话结论

「每段风格不一样」的原因是**五套收尾层的材质参数不是一套数**（暗角 0.38–0.45、颗粒 0.035–0.040、
辉光 0.25–0.42、黑位 0 / +0.012 / +0.014、D 组 paper_mode 还会把暗角砍到 0.15、颗粒放大 1.4×）。
本层把这五项 + 中性色温 + 红色纯度换成**全片唯一一套目标值**，实现方式是「先等量扣掉作者的材质，再按统一
目标重做」——所以构图、明暗设计、内容调色（冷灰 / 暖金 / 宣纸留白 / 单点光极暗）一个没动。

在同一张标准测试板上量，八种收尾层之间的材质离散度（max−min）：

| 指标 | 收敛前 | 收敛后 |
|---|---|---|
| 颗粒（等效振幅） | 0.0020（最低段比中位低 11%、最高段高 46%） | **0.0005（±7%）** |
| 暗角（角/中比） | 0.1915 | **0.0990** |
| 黑位（纯黑板亮度） | 0.0094（3×） | **0.0012** |
| 辉光（光晕量） | 0.0120 | **0.0051** |
| 中性色温 R−B | 0.0800 | **0.0418** |
| 暗红纯度 | 0.0872 | **0.0476** |

接点（切点）前后 ±15 帧的成对统计差，六接点平均：颗粒 **−81%**、色温 **−40%**、σ **−29%**、
亮度均值 **−14%**（后两项受切点内容支配，见 §4.3 的说明）；渲染开销 **+0.19 s/帧**（≈ 3–12%）。

## 2 设计

### 2.1 三条原则

1. **只动材质层，不动设计层。** 亮度均值 / σ / 构图 / 明暗是设计，一律不拉平；
   收敛对象是「颗粒强度与频率、辉光量、暗角曲线、黑位/白点、中性色温偏移、红色纯度」。
2. **可逆则精确逆，不可逆则有界。** 颗粒核、暗角曲线、辉光算子在代码里是确定的，可以**等量扣掉**再重做；
   色温/红纯度这类不可逆的，只做**有界小补偿**（±4–6%），绝不做「一刀切」。
3. **默认关闭。** `GRADE_UNIFY=0` 时 `apply()` 恒等返回（同一对象、零开销），随时 A/B 与回滚。

### 2.2 七个阶段（顺序即物理顺序）

| # | 阶段 | 做法 | 精确性 |
|---|---|---|---|
| 1 | **统一颗粒** | 逐帧最小二乘**反解作者实际加的颗粒振幅** a_hat（用 12 个颗粒核里 `int(t*30)%12` 那一个，与 `c1kit._grain` 逐像素同源），先整段扣掉，最后再按统一振幅 a_tgt=0.040 重加 | 实测反解误差 <1%（0.0400 / 0.0350 / D paper 0.049 全部对上） |
| 2 | **黑位 / 白点** | 只动近黑（掩膜 `1-smoothstep(0,0.10,L)`）与高光肩区，把纯黑板亮度收到 0.0100、纯白板收到 0.848 | 静态表 + 有界 ±0.005/+0.010 |
| 3 | **辉光** | 同一算子做差量：`bloom(0.72, a_t) − bloom(thr_a, a_a)`，1/4 分辨率算，幅度上限 0.06 | 一阶精确（同算子差量） |
| 4 | **暗角** | 直接换曲线：`(mask(0.42)/mask(vig_a))^0.60`，结果限幅 [0.90, 1.10] | 指数 0.6 = 只收敛一半，保住「单点光极暗」「宣纸平铺」 |
| 5 | **中性色温 + 红色纯度** | 段落级对角 3×3（保亮度归一）+ 红色族色度增益，两者都有界 | 力度 0.40 / 0.50，限幅 ±6% / ±8% |
| 6 | **接点局部匹配** | 6 个接点各存一组 (gain, contrast, tint)，满强度 0.35 s，smoothstep 到 2.0 s 归零 | 上限 ±6% / ±5% / ±0.04 |
| 7 | **加统一颗粒 + 复位黑边** | 统一核、统一振幅（`gs` 按段 ±4% 微调）、亮度调制 `0.35+0.65(1−L)` 与作者完全同式 | 与作者同源 |

`2.39 黑边`、`t` 的用法、颗粒核索引 `int(t*30)%12` 都与作者代码逐字对齐（连浮点截断的边界行为都一致）。

### 2.3 为什么不用「统计拉平」的办法

我先按「把相邻段统计量拉进同一窄带」的思路量了实拍数据（见 §4.3）：**接点两侧的亮度均值差本身
就在 0.09–0.40 之间**，那是切点两边的内容/镜头设计（C→D 的切黑接白纸虚空、D→E 的宣纸→血场），
用增益去抹平等于改分镜。所以：
- 亮度/反差只做 **±6%/±5% 有界收敛**（实测把 σ 差收窄 29%、均值差收窄 14%），
- 真正的收敛放在**材质层**：颗粒 −81%、色温 −40%，这两项才是「一眼看出换组了」的原因。
- 全局色温补偿**只针对收尾层自身的中性偏色**（宣纸暖白 vs 冷灰），不碰内容调色（`COLD`/`WARM`/`GOLDW`）。

## 3 参数表

### 3.1 统一目标 `TGT`

```python
grain=0.040, grain_jitter=0.10        # 颗粒等效振幅（允许按段 ±10%，实际用 ±4%）
vig=0.42, vig_beta=0.60, vig_clip=(0.90,1.10)
bloom=(0.25,0.35), bloom_thr=0.72, bloom_sig=26.0, bloom_clip=0.06
black=0.0100, black_clip=(-0.005,0.010)
white=0.848
cast_rb=-0.030, cast_strength=0.40
red_pur=0.860, red_strength=0.50
```
取值的依据：**每项都取八种收尾层的中位数**（vig 0.42、grain 0.040、bloom 带 0.25–0.35、黑位 0.0100），
即「谁都不是标准，但大家都往中间靠」；`cast_rb=-0.030` 是全片「冷灰底」的既定色相，只收敛偏移、不改色相。

### 3.2 各段作者参数 `SEC`（补偿用）

`vig / bloom / thr / grain / black / white_clean / cast_rb / red_pur` 全部是 §1.2 量出来的实测值；
D 组额外带 `*_pm` 斜率（`vig_pm=-0.30, bloom_pm=-0.18, thr_pm=0.17, grain_pm=0.40, black_pm=0.0022,
white_pm=0.0394, cast_pm=0.0792`），所以 `hint={'pm': paper_mode}` 一给，D 组任意 paper_mode 都能精确定位。
`gs`（颗粒按段微调）= A/B/副歌 1.00、C 0.98、D 1.04、E 0.96（亮段略加、中间调略减，均为 ±4%）。

材质量（颗粒、暗角、辉光、黑位、色温）才是「换组了」的信号，它们已经收到同一窄带。

## 6 已知取舍与残余差异（都是有意留的）

1. **D 组 paper_mode 段（2:41–2:57 宣纸留白）只收敛一半。** 它的暗角 0.15 是「整幅纸面平铺」的设计，
   强行拉到 0.42 会让纸边压暗 30%。本层把它收到 0.9059 → 0.8252（角/中比），色温 +0.0349 → +0.0053
   （暖白保留一半），颗粒 0.056 → 0.040。**它仍然是全片最亮最通透的一段**——这是用户认可的样片。
2. **辉光用「带」不用「单值」（0.25–0.35）。** C 组 0.42 压到 0.35（光晕 −17%），E 组 0.25 原地不动
   （已在下沿），D paper 从 0.12 抬到 0.25 但幅度上限 0.06，避免把宣纸灌成雾。
3. **亮度均值/σ 的接点差只能收 14%/29%。** 剩下的是内容与转场设计（§4.3）。如果你要更狠，把
   `JOINT` 的 gain/contrast 限幅从 ±6%/±5% 放到 ±15% 就能做到，但那是改分镜，本层默认不做。
4. **E 组最后 66 帧（f ≥ 7174，收墨落版）不接本层。** 那段代码在 `finish()` 之前就 `return` 了
   （作者故意「不加颗粒/暗角，干净落版」），本层挂在 `finish` 之后，因此自然不作用——与前一段的
   颗粒连续性差 2 s，属于作者既定设计，未强行修改。
5. **红色纯度只在材质层收敛**（暗红 `(r−max(g,b))/r`：0.812–0.899 → 0.828–0.875），接点处不按
   「红色面积」对齐，理由见 §3.3。
6. 单帧级 `a_hat` 在极暗/过曝帧（如 161.30 s 的切黑帧）会反解失准，已加安全带
   （限在名义值 0.4×–1.6× 之间），这些帧的颗粒不会被「加两遍」。

## 7 复算 / 复核方法

```bash
PY=out/full_sprite/chunks/local60_149c727_20261109/venv/bin/python

# 材质指纹（不渲染画面，几秒）
$PY tools/grade_unify_cmp.py --probe          # → out/grade_cmp/material_probe.json

$PY tools/grade_unify_cmp.py --frames 300,2700,3600,4900
```
