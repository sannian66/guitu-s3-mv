## 0. 这一版做了什么（先说结论）

用户 19:2x 拍板 **蒙皮/骨架路线砍掉**。我把整个变形层删了（权重场、骨架链、`cv2.remap` 蒙皮、
洞补 inpaint、转头挤压、`arm_r`/`lean`/`twist`/`knee`… 全部删除），只留三种**纯摆放**能力：

| 能力 | 参数 | 规则 |
|---|---|---|
| 整姿势键帧替换 | `key='idle'\|'raise'\|'slash'\|'draw'` | 只在切点换；过渡 ≤2 帧交叉 + `mblur≥7`，**不允许半个姿势** |
| 表情贴脸 | `expr='angry'\|'smirk'` | 静态贴一次，镜内不变；只允许配 `key='idle'` 且无角度溶解 |
| 角度交叉溶解 | `angle`,`angle_from`,`mix` | 两张图各按自己的脚底/眼线摆好直接叠（**不做几何变形**），只在硬切那 1~2 帧用 |

传 `head_turn / arm_r / key_w / knee / ...` 一律 `ValueError`，错误信息里写清「为什么废弃」。

**单帧成本**（3.12 venv、`h=680`、单进程、线程=1）：`idle` 33–37ms、`raise` 41ms、`slash` 49ms、
角度溶解 40ms、`expr` 37–43ms、带 `mblur=9` 的键帧 64–84ms。**全部低于 90ms，且比原 sprite
（同高度同调色 ~95–250ms）更快或相当**。

### 逐镜诚实结论

**S043 特写 —— 能用，但只在特定尺度。**
`expr='angry'` 贴上去后眉毛/嘴角都变了，没有任何拉伸/黑带。问题是特写尺度（脸 ~420px 宽）下
贴片比原脸大 8~10%，边缘有一圈很淡的接缝。**建议**：脸 ≤120px（中远景）才用表情贴片；
这个特写要换表情，正路是**另生一张 S043 的 angry 特写**，走 `key` 硬切（素材问题，不是代码问题）。

**S039 缓行 —— 做不出增益。**
骨架砍掉后，rig 对这张走路立绘能做的只剩「摆放（位移/±0.9% 身高微差）」，而原镜头已经有 6px bob，
**所以两版几乎一模一样**。滑行感的根源是「一张静态走路帧 + 平移」，不是 rig 能修的。
**建议**：S039 保持现状；真要治，补 2–4 帧走路序列图（同一个机位、同一套衣服，只改腿/手/衣摆），
用角度溶解那套机制在步频上做 2–4 帧循环硬切即可 —— 那属于「多一张生图」，不需要骨架。

**S045 旋斩 —— 做不出来（按你的话：诚实说做不出来）。**
`raise→slash` 两个整姿势键帧做出来的东西**干净但没有旋斩**：真实的旋斩需要 90°+ 的转身和
衣摆/马尾离心飞起，而 `pose_raise` / `pose_slash` 都是站定的姿势；rig 不可能凭空转出转身
（这正是被砍掉的蒙皮想做而做坏的事）。
**建议**：S045 继续用现在三张专用精灵（windup/spin/finish）+ 甩入模糊。资料齐、效果已验收，不要动。

## 3. API

```python
from units.rig_sprite import PoseRig
rig = PoseRig(base='assets/gen/char', work_w=2048).warm()   # 载入时 warm() 一次（~1.3s）

# 1) 整姿势键帧（切点替换）
fr, a = rig.play(fr, t, 'raise', dst=(960, 900), h=680, grade=G, rim=R, wrap=0.45)
#    过渡帧：rig.play(..., 'slash', mblur=(-14, 0))  ← mblur≥7 盖住 ≤2 帧的交叉叠影

# 2) 表情（静态，镜内不变）
fr, a = rig.play(fr, t, 'idle', dst=..., h=..., expr='angry', keep_red=0.0)

# 3) 角度交叉溶解（只在硬切那 1~2 帧）
fr, a = rig.play(fr, t, 'idle', dst=..., h=..., angle='tq_r', angle_from='front', mix=0.5)

# 镜头实验用「单图 rig」（直接用该镜头自己的立绘，保住原美术）：
rig = PoseRig(images={'idle': '/abs/path/xxx_cut.png'}, work_w=2048).warm()
```

* `dst` = 脚底中点；`h` = 人物总高（脚底→头顶发梢）像素。半身键帧（`draw`）自动按**脸对齐**，
  当特写插镜用时把 `h` 调大（构图由 `h` 控制，没有别的缩放参数）。
* `grade / rim / look / alpha / defocus / mblur / wrap / shade / keep_red` 与 `units/sprite.py`
  的 `SpriteLayer.draw()` 同名同义；`look` 直接复用 `sprite._look` + `red_mask`（没有抄第二份）。
* 角度表：`front` / `tq_r`（生图只转了约 20°）/ `tq_r45`（等 `hero_view_tq_r45_cut.png` 到位后启用，
  现在缺文件时自动回退 `tq_r`）/ `side_r`。

## 4. 已废弃（原因）——**不要再往回加**

| 废弃的东西 | 为什么 |
|---|---|
| **蒙皮变形 / 权重场 / 骨架链 / `cv2.remap` 蒙皮** | 二维单张立绘**没有手臂底下的像素**：手臂转开就把背景挖空，靠 inpaint 补出来是一团糊；大袖在腋下必然塌成一坨。边际收益为负。 |
| `head_turn`（头部角度挤压/替换） | 侧脸图和正面图直接混 → 脸上一道横向黑带；挤压版还会让头侧悬一块与头断开的发团。 |
| `head_pitch` / `lean` / `twist` / `knee` | 这些全靠蒙皮实现，同第一条。 |
| `arm_r` / `arm_l` / `elbow_r` / `elbow_l` / `sword` | 抬臂/屈肘/转刀=蒙皮；`sword` 还需要把刀单独切层（图层间没有遮挡关系）。 |
| `key_w`（键帧中间值） | 「半个 raise + 半个 slash」= 两个人影叠在一起、四把刀（用户原话）。过渡只能用 ≤2 帧交叉 + `mblur≥7`。 |
| `key_zoom` | 半身键帧改为自动按脸对位，构图统一用 `h`。 |
| `expr='calm'` | 等价于不传（直接用 base），留着只会让人误以为要贴图。 |
| `expr='look'` | 侧脸特写贴到正面图上必然错位（实测横向黑带 + 灰块），只保留 `angry` / `smirk`。 |
| `body_turn`（身体转身） | 需要另一套正身角度图或蒙皮；交叉溶两张不同姿势的正身 = 双影。 |

## 5. 已知限制（不修，写清楚）

1. **`mix` 中间值 = 两张图直接叠（双影）**。这是「交叉溶解」的定义，不是 bug；只在硬切 1~2 帧用。
2. **表情贴片的脸宽标定取自皮肤块**，与真实脸宽差 ~8–10%；脸小的镜头看不出来，特写尺度能看出接缝。
3. **`key='draw'`（半身键帧）是特写插镜**：把 `h` 调大到脸铺满画面时，会看到源图自己的画框边（一条直边），
   构图时把那条边推出画外即可。
4. **`pose_slash` / `pose_raise` 是站定姿势**，不能表达转身/离心飞起的衣摆 —— 旋斩类镜头请继续用专用精灵。
5. 解码 mip 上限 2048；`work_w` 只影响贴图清晰度，不影响几何（几何固定按 1024 测量再换算，
   同一张图换 `work_w` 结果完全一致）。
