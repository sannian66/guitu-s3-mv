## §0 歌词排版规矩（2026-11-09 19:0x 用户否决「全句道具化」后重定 · 可直接抄进 HANDOFF）

> **一句话**：字幕是主，道具只抬重音。上一轮把这句字从字幕搬进画面 —— 方向错了，本节推翻它。

1. **每句歌词必须有字幕层。** 右竖排（字心 `x≈1752`，首字 `y≈262`）或横排偏下居中（`y≈850`），
   沿用现有 `lib/typo.py` / `units/lyric3.py` 的字号（整句 62px）、字距（横 0.22em / 竖 0.30em）、
   暗衬与逐字墨显，**不许自创排版**。
2. **道具化只针对关键词**，1–3 字（最多 4 字），并且要**从字幕里抽走**这个词 ——
   字幕里该字留空（或极低透明度占位），**不允许同一个词在字幕和画面里各出现一次**。
3. **不新增视觉中心。** 道具必须顺着画面已有结构长出来（砖缝 / 刀身 / 秤杆 / 匾额 / 纸边 / 水面 /
   门钉 / 铁闸），**不得压脸、不得压对称轴、不得进人物动作区、不得抢走主体注意力**。
4. **每镜最多一个道具词**；同一段 15 镜内同一手法（刻 / 印 / 擦 / 烧 / 穿线）不重复
   （承接上一轮的转场去重规则）。
5. **关键词必须是该句的重音**：对 `align.json` 的逐字时长取最长者，或字幕里已被标朱红的那个字。
   不许随手挑一个顺手的字。

**自检口径（出图固定三联）**：左 = 纯字幕 ／ 中 = 旧版全句道具化（已否决，留作反例）／
右 = 新版「字幕整句 + 关键词道具」。先自己判断「排版好看、不抢注意力」再交出去。

**已被用户否决的做法（别再犯）**
- 把整句诗塞进画内当道具（原话：「排版不好看、没融入画面、很丑、抢注意力」）。
- 在对称构图中间插字（例：把「定」压在「正」「邪」之间，破坏对称）。

**本节取代以下段落的口径**：§1 清单里的「改造方案 / 实现要点」按本节重读；
§4「已实施」、§5「接线清单」、§6「只做关键词」三段里的**行号接线与整句道具化实现均作废**，
以 §8 重做版为准（§6 的结论正好被本节吸收，保留作论证）。

> 目标：把 56 句里仍属**屏幕层排版字幕**的句子，改成「字是画面里的道具」——
> 和用户喜欢的三段（1:30–1:40 算盘珠拨字、1:58–2:04 朱红丝线挂字、2:41–2:57 铅字砸纸/朱印盖没/烧穿）同一套语言。

> 只管「字怎么进画面」，**不动** 2.39 黑边、不动黑白灰+朱红+金、不动人物与运镜。

## 2. 试点结果（L15 / S034「若规则是铁壁铜墙」，刻）

### 代码

- 新文件：`units/props_dev.py`（**只新增**，未改任何 `sec_*.py` / `*_kit.py` / `sprite.py`）。
- 可复用函数：**`etched_lyric(fr, text, box, times=None, t=None, layout='v', cols=1, size=None,
  font='serif_b', depth, light, dark, hl, hl_amt, groove, lip, hot, bite, chisel, dust, …)`**
  - `prop_layout()`：把一句歌词排进一个画内矩形（竖排分列 / 横排 / 方阵），自动定字号；
  - `prop_mask()`：字位 → 全帧 alpha（**印/擦/烧/穿线**四类后续直接复用这一层，只换最后一步合成）；
  - `_engrave()`：阴刻浮雕（字槽压暗 + 背光内壁投影 + 迎光内壁高光）——公式同 `units/a_r6.py:engraved()`，
    收进包围盒子图实现（全幅 1080p 每次 2 处 `warpAffine` ≈ 25ms，子图 ≈ 4ms）；

    追加，因为 `a_r6.engraved()` 只管槽内；

### 自评（优点 / 不足都要说）

**成立的地方**
1. **不再是字幕**：字没有暗衬带、没有描边框，读的是**光**不是颜色；和同一镜里从砖缝浮起的巨字「墙」是同一个世界。
2. **侧光即物理**：`light=(-1,-0.35)` 吃的是 S034 自己的掠射光，所以字只在「迎光那一面」有亮边——这正是阴刻和「描边字」的区别。
3. **逐字凿进成立**：凿口崩边 + 槽底凿痕 + 石屑三件套让「字是被凿出来的」这件事一秒内自证；字面永远不缩放，只加深（凿子不会把字弹大）。
4. **朱红关键字保住了**：`hot='墙'` 把规范里的「每句至多一个朱红字」搬到槽底，不牺牲色板又不出戏。
5. 复用度：`prop_layout`/`prop_mask` 是所有 5 类手法共用的底座；`刻` 只多出一个 `_lip`，其余直接复用 `a_r6.engraved`、`c_kit.cast_metal`、`e_r7.self_burn_glyph/burn_hole`。

**还不够的地方（按优先级）**
1. **跨砖缝**：字块横跨 3–5 皮砖，笔画被砖缝的高光打断（真实碑刻不会）。下一版建议：按砖块行列给每个字单独的 `box`（第 12 处已这么设计），或把 8 字缩到 2×2 方阵坐在单块石面上。
2. **左列偏暗**：「若规则是」一列落在暗砖上，对比偏弱。数值上把 block 右移 60–80px（`box=(200,150,720,960)`）实测更亮，但会蹭到巨字「墙」的笔画，需要与巨字一起重排。
3. **平光镜头不可用**：阴刻完全依赖侧光。凡是平光/正面光的镜头（如副歌一几个正面 CU），必须先补一盏「虚拟侧光」（在 `etched_lyric` 外先按 `light` 方向给底材加一层亮度梯度），否则字会消失——这条要写进美术规则。
4. **4:2:0 编码衰减**：朱红槽 + 冷亮边在 H.264 yuv420 下会掉一档，合成端预留 8–10% 亮度（本试点已把 `hl_amt` 压到 0.48 仍在成片里偏灰）。
5. **石屑参数敏感**：`dust=0.9` 在暗底上刚好，换到亮底（纸/白天）会脏，需要按镜头亮度给 0.4–0.9。
6. **文字层级**：和 260px 巨字同框时刻字必须更暗更小（本次已压到 172px / `dark=0.9`），否则两个文字系统打架——这条对第 17 处（与「铜墙」巨字同镜）尤其要小心。

# 6. 一条设计决定（结论已被 §0 吸收，保留作论证）

**道具化只做「关键词」，不做整句。** 依据：
1. 用户喜欢的三段本身就是这个规律——1:30 段只把「算」做成算盘、2:41 段只把「人」做成朱印、刻刀只刻「大局」二字，没有一处是把 11–15 字的整句做成道具。
2. 实测（第 4.1 节 S034 八字整句版）：整句要塞进一个画内载面，透视墙上字号差 2.3×、砖缝切断笔画，既不像刻也读不出；改成「关键词 4 字 + 一字一砖」立刻立住。
3. 代价：改造后该句只显出关键词，其余字靠演唱承载。这与全片已有做法一致（多数镜头本来也只出 2–4 字）。

**可回滚点**：`_ITEMS` 里每项的 `key=` 就是关键词，删掉 `key` 就退回「整句道具化」（`text` 一直是整句）；两种模式同一个函数，不需要改代码结构。

## §9.5 烧类验收口径（lead 2026-11-09 19:2x 确认，与擦/穿线/印共用）

1. **烧穿必须有「背后」**：洞内露出的东西必须比载面**更亮或更冷**（才读成"穿透"）。
   背后也是暗的 → 走「**纯黑 + 14% 暖雾 + 洞缘焦红**」，**绝不用同亮度的暗块**（那是脏斑）。
2. **焦边三段式**（沿用 `e_r7.burn_hole` 三层）：暗褐焦痕（20–40px）+ **断续**橙红火线 + 卷起碳化黑边。
   火线必须断续 —— 连续烧一圈就变成"描边"。
3. **字要自燃**：从字头那个字开始、沿线往下走，不是整句一起烧；每字起点对齐 `align.json` 的字头时间
   （`burning_lyric(times=…, t=…)` 已经这么实现）。
4. **同一镜头只能有一个烧的对象**（字 或 纸，不许字和纸同时烧）。
5. **L54 的孔缘暖亮线定档 0.38**（不是 0.55）：这一镜的气质是"空、冷、静"，勾边只到"能认出是洞"就停。

## §9.6 通用规则：时序特效必须标时间窗（写进三联图表格）
所有**有时序的特效**（烧 / 擦 / 穿线）在验收材料里必须给出：
- **出现帧**：字头那帧（`align` 该字的 `t`）；
- **消失帧**：特效结束帧（自燃烧尽 / 擦除到 70–80% / 丝线崩断）；
- **3 帧条**：`t=字头` / `+0.3s` / `+0.6s`，文件命名 `<批次>_<句号>_seq.png`。
理由：单帧抽在错的时间点会得出完全错误的结论 —— L08 第一次验收就栽在这（f=1281 时 `self_burn_glyph`
已经把字烧没了，右图看起来"什么都没加"）。这条对所有时序特效强制。

## §9.7 擦类口径（按 lead 指定）
**别擦到底**：擦除进度封顶 **70–80%**，留一点残墨。理由有两条 ——
① 擦到底会露出一块"干净得不自然"的区域（我们不去反算底图，没法真正还原底材）；
② 擦到 7–8 成更像"擦过但没擦净"，符合"刮擦/雨冲/手抹"这类动作的真实感。

## 10.4 耗时增量（诚实口径）
- **无法用同帧 A/B 直接测**：同进程里先后渲同一帧，第二帧吃满缓存，delta 被缓存噪声淹没（实测出现 −25s~+0.3s 的荒谬值）。
- 用**孤立调用实测**（暖缓存、min-of-3）：单字 擦 111–128ms / 穿线 152–172ms / 印 89–94ms / 烧 57–64ms / 刻 35–71ms。
- 整片口径估算：20 处 × 平均 95ms × 平均句长 3.4s×30≈102 帧 ≈ **+195s**；
  但道具只在**字头之后**才画（多数镜头后半段），按 60% 计 ≈ **+117s**，占全片 1306s 的 **≈9%**。
  精确值要等整片重渲一次才能给。

### dupcheck 结果（`LYRIC_UNI=1 GRADE_UNIFY=1 SPRITE_FAST=1`，20 帧）

**诊断（重要）**：这 6 处残留块的坐标**都不在道具框内**，例如 f600 残留于 `(81,342) 27×35`，而 L02 的道具框是 `(900,200,1700,560)`；
