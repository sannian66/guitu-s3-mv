## 逐项理由

### 1. 节奏卡点 13/15
- ✔ 切点落拍。平均镜头时长在限内。V18 写实拳头配「握在自己」逐字出现，卡得很准。
- ✘ V02（约 1.7s）只有雨和极慢推近，人海本身不动。
- ✘ V06 近乎定格；V07 起、中、止三帧几乎一样（权杖和手都不动，只有光）。

### 2. 分镜设计 13/15
- ✔ V08 刀尖立字、V01 撞钟、V16 斩碑、V20 → V21 倒影翻转、V09 / V10 算盘梁，设计感成立。V07 / V08 撞构图已解。
- ✘ V12 仍是全段最弱的一镜。
- ✘ 主歌二开场仍然是 V01 / V02 两个没有主角、没有歌词的大景，合计约 3.3s。

### 3. 精致度 12/15
- ✔ 手部问题解决。V11 秤杆、V16 石碑、V24 / V25 朱红轮廓光都是商业级。
- ✘ V02 复制阵列：标杆副歌一里没有这么「游戏批量实例」的画面。
- ✘ V01 入帧 f2586–2589 的红团像脏点。
- ✘ V17 掌心「命」是一块平涂的朱红剪影（见歌词项），压在软焦的手上，质感廉价。
- ✘ V18 拳头上沿有白描边，影调比场景亮一档，略有贴图感。

### 4. 歌词排版 13/15
- ✔ 金字同质化明显缓解：「天命」「嚣张」都去了金，「握」改成朱楷。
  - 剩下的金字是 P05 匾「规矩」、P14「滚烫」、V04 笏板「大局」、V10「算 / 够」、V16 碑「上苍」，而且都附着在物件上。
  - 唯一还漂着的大字是 V03「顾全」（白字，不再是金字）。
- ✘ **V17 掌心「命」可读性差**：f3215 / 3219 放大后，字形被压扁，糊成「屋顶 + 三竖」，读不出「命」字。这是「谁的命都握在自己手掌」这句的核心字。
- ✘ V12「的人」偏弱。
- 小提醒：P08「天」在 f1574 被裂缝劈开后，左上多出一个钩，瞬间可能被读成异体字。只停一拍，不扣分，但建议把裂缝避开横画起笔。
- 其余逐字核对没有发现错读：「可曾有机会」「嚣张」「牺牲多少人」「分量」「黑白颠倒」「锋重新划」「出新方向」。

### 5. 不重复 8/10
- ✔ 「手握杆状物」从 4 次降到 3 次（P14、V07、V18），V15 去掉了城墙。
- ✘ V20 / V21 仍然用城墙，和副歌一的墙段近。
- ✘ 86.19–89.40 的归属仍需总导演确认（本评审无法核实）。

### 6. 转场 8/10

- ✘ punch 仍偏多（V18、V22 在关键帧里可见）。
- ✘ V01 入帧红团让第一个切点显脏。

### 7. 人物 8/10

- ✘ 束发 / 披发仍然交替。
- ✘ V18 写实摄影手和 CG 鬼屠在质感上有落差，靠调色勉强接住。

### 8. 情绪叙事 8/10
