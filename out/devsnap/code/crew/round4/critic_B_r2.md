总分 **74 / 100**。有两项低于 70%：精致度 10/15、不重复 6/10。另有 1 个「不可交付」镜头：V13 开头 6–8 帧穿帮。

**主歌二（V01–V25）还拖后腿**，问题有三：
1. 六个镜头是「金色发光大字压在暗背景上」，同一种处理，字成了画面本身，看着单调、偷懒；
2. 和副歌一有 5 处撞概念或撞时间线；
3. 有一处穿帮，几处调色和抠图没收好。

## 逐项理由

### 1. 节奏卡点 13/15
- ✔ 两段所有切点都落在 `analysis.npz` 的拍点上，误差 ≤1 帧。导歌一 15 镜平均 1.03s，主歌二 25 镜平均 1.26s，都远低于 2.5s 的要求。字头卡得准：P02 落墨卡 45.38，P04「框」卡 47.70，P06「血」卡 49.62，P08「天」卡 52.14，P09「命」卡 52.84 / 回撞 53.17，P11「当」卡 55.10，P13「刀」卡 56.50。P15 在 59.13 鼓停时压暗憋住，再交给副歌一 S028，设计得好。
- ✘ **V13（100.58 起）开头约 0.2s（f3016–3022）只有雨，画面是空的**，人物到 f3027 才出现。这正好压在「可」（100.62）上：人声起了，画面还没东西。（-1）
- ✘ **V16「上苍」**：「苍」字头在 105.16，可到 f3162（≈105.4）字已经开始被吸进中心点，f3170 只剩光点。关键字能看清的时间约 0.25s，不到 1 拍。（-1）

### 2. 分镜设计 11/15
- ✔ 导歌一景别交替清楚：ECU → 微距 → MS 俯 → LS 后拉 → LS 仰 → CU → MS 仰 → ELS → MCU → 斜俯 → 微距 → MCU → MS → CU → LS。图形匹配也够：P03→P04 框、P12 rect、V06 circle、V09 rect，满足 ≥3 处的要求。
- ✘ **主歌二有 2 个镜头基本只剩字**：V14「反抗」只有字、红晕和火星；V16「上苍」只有字和放射速度线。这两镜没有前景、中景、后景三层，没有母题，也没有人物。用户说的「画面简单」指的就是这种镜头。
- ✘ **主歌二相邻镜头构图撞车**：
  - V07 → V08 连着两镜都是「反派手握权杖、刀柄 + 大金字」，景别和方向几乎一样；
  - V17 → V19 是两个鬼屠在雨中正面 MCU（中间只隔了 0.8s 的 V18 拳头）；
  - V20 / V24 / V25 三镜都是「LS 小人立在城墙垛口地平线前 + 雨」，构图母板相同。
- ✘ V12「被牺牲的人」：灰色纸人斜躺在黑底上，没有空间、地面或光源，看着像漂在画面上的贴图。

### 3. 精致度 10/15
- ✔ P02 朱砂晕染、P05/P06 朱漆门钉加血幕、P10 铅字浮凸、P14 刀身烧红加热浪、P11 铅字盘虚焦，这几镜的质感已经是商业级。
- ✘ **V13 穿帮（不可交付）**：f3017–f3022 画面下方正中有一个**硬边黑色圆角矩形**（约 x 1340–1410、y 380–480 / 1080p），像精灵入画前被裁出来的一块。
- ✘ **V24 / V25 人物是纯黑剪影平贴**：没有轮廓光，边缘没有雨的交互，和背景的雨、雾不在同一层空间。V24 人物只占左下约 1/8 画面，其余是灰雨。（f3471、f3513）
- ✘ **V18 拳头、V08 抚刀的手是暖色肉色**，放在近乎黑白的雨夜里像外部素材贴进来的；P14 有烧红的刀做光源，所以成立，这两镜没有。
- ✘ V03 / V04 百官是同一个模型复制成阵列，姿势和间距一致，像人偶。标杆副歌一里没有这种廉价感。
- ✘ V08「嚣张」的 RGB 错位故障字，V16 的放射速度线：这两种是模板化特效，和水墨、朱砂、金属的整体质感语言不统一。
- ✘ P05：f1445 起，下摇时匾额「规矩」的上半截被画框顶边裁掉，而且持续半拍以上。

### 4. 歌词排版 11/15
- ✔ 导歌一的字和画面互动很充分：朱笔逐笔写、朱砂浸红「生死」、「框」被真框住、金箔字被门缝切断、「血」从门缝渗出下流、云隙负形「天」被闪电劈开、「命」阴文印被刀柄撞碎、铅字「理所应当」被刀尖挑起、「刀」被刀弧斩开、「滚烫」火烧显字。主歌二里的屏风竖排「可大局背后」、算盘梁刻字、「黑白颠倒」倒排，也都好。
- ✘ **主歌二的金色发光大字重复 6 次**：V04「大局」、V07「权」、V08「嚣张」、V10「算够」、V11「量」、V16「上苍」，同一套粗宋金色加辉光。这违反「每段一套、不复用」的精神，也正是用户说的「歌词文字排版简单」。
- ✘ 可读性：
  - V14「反」用朱红行书，读起来像「及」；
  - P13「刀」在 f1705–1712 被斩成碎块，读成「刃」或「习」；
  - V23「重」的行书读成「壬」或「去」；
  - V16 左上的「不」贴着画面顶边，f3162、f3170 都有部分出画；
  - V12 竖排「的人」后两个字很弱，几乎看不见。
- ✘ 同一句里混用字体，看着没规矩：V14 左边是红行书「反」，右边是白粗黑「抗」；V16 白行书「不」、红楷「问」、金粗宋「上苍」，三种字体挤在一个画面。

### 5. 不重复 6/10
撞标杆副歌一（`units/chorus1.py` 的镜头标题注释可以对照）：
- **V01 / V02 和副歌一 S047 / S048 时间线重叠，概念也一样**。副歌一 S047（86.19–87.56）是「刀斜插泥地 + 夜雨 + 小款鬼屠朱印」，S048（87.56–89.40）是「雨滴落下，镜头追进雨滴，滴中倒映」。B 组的 V01（86.19–87.53）是插地刀 + 雨，左下还有小款；V02（87.53–89.40）是追进雨滴、滴中倒影。成片只能留一版，现在两边都在做同一件事。
- **V11「量」金色方印 ≈ 副歌一 S043「量」方印**：同一个字，同一种印式处理。
- **P15 LS 低机位举刀向天 ≈ 副歌一 S030 LS 月下举刀指月**：而且 P15 之后紧接着就是副歌一，两段离得很近。
- **P12 刀身加脸（刀竖在脸前一分为二）≈ 副歌一 S038 刃面倒映眼睛**，属于「刀和脸」同一母题。
- **P06 朱红巨字「血」，10 秒后副歌一 S028 又是朱红巨字「血」**，接缝两边重复。

段内重复：
- 城墙垛口地平线做背景 5 次（V15、V20、V21、V24、V25）；
- 生死簿纸面 3 次（P01、P02、V11）；
- 金色闪白 3 次（P11、V04、V07）。

### 6. 转场 8/10
- ✔ 种类多，远超「至少 5 种」：导歌一用了 12 种（flashr / paper_tear / ink_bleed / flash_white / cloud_wipe / glitch_cut / slash_wipe / gold / match_cut / flash_red / punch / shatter），主歌二也有 12 种以上（zoom_dark / iris_moon / occlusion / split_slide / rain_curtain / match_cut 等）。P04 同机位后拉接框、V03 雨滴开圆接队列、V20 水面线分屏，都有设计感。
- ✘ 闪类转场是拐杖：40 个切点里有 8 个是闪（P02、P06 flashr；P07 flash_white；P11、V04、V07 gold；P13、V14 flash_red）。
- ✘ 主歌二有 4 处 `hard`（V10、V17、V19、V25）和 2 处 `none`（V13、V21）。其中 V13 的 `none` 直接切进那段空雨加穿帮，没有冲击；V25 的 `hard` 是段尾收束，也没有冲击。

### 7. 人物 7/10
- ✔ 表演对得上歌词：P09 握拳对「命」，P09 刀柄回撞对「不信」，V17 摊掌对「谁的命」，V18 握拳对「握在」，P15 举刀，V22 拉开架势对「那就用刀」。
- ✘ 鬼屠有两种造型交替出现：束发马尾（P07、P13、V13、V15、V20）和披发（P09、P12、V17、V19）。没有叙事交代，观众会以为是两个人。
- ✘ V08、V18 的手不跟场景色温（见精致度）。V24、V25 剪影没有轮廓光。V12 纸人飘浮，没有受光方向。

### 8. 情绪叙事 8/10
- ✔ 导歌一从冷纸面上的「规矩」推进到烧红的刀，最后在 59.13 憋住再爆进副歌，弧线清楚。主歌二在雨夜里从「世人、权柄、牺牲」走到「自握命运、黑白颠倒、用刀划出方向」，结尾的朱红裂地线指向前方，落点准。
- ✘ 主歌二中段（V12–V14）情绪掉下来：V12 纸人飘浮太弱，撑不起「被牺牲」；V14「反抗」只剩字，没有任何「反抗」的动作。这个位置本该是主歌二第一次抬头。

## 返工清单

### P0（不修不过线）
1. **V13 穿帮和空镜头**：去掉 f3016–3022 的黑色硬边块。人物从第一帧就在画内，或者让人物从雨里升起的入画在「可」（100.62）之前完成。转场把 `none` 换成有冲击的设计。
2. **V01 / V02 和副歌一 S047 / S048 的时间线重叠**：交总导演定 86.19–89.40 归谁。如果归 B，就必须换掉「插地刀 + 雨滴追进」这个概念，不能复刻副歌一；如果归副歌一，就删掉 V01、V02，让主歌二从 89.40 开始。
3. **金色大字去同质化**（V04、V07、V08、V10、V11、V16）：至少 4 镜换成「字和物件互动」的处理。可以这样做：
   - 「大局」刻在百官笏板上；
   - 「权」烙进权杖木纹；
   - 「嚣张」被反派的手指捏出来，或从扇面展开；
   - 「量」不用方印（撞 S043），改成秤杆刻度。
   去掉 V08 的 RGB 故障字。
4. **V14「反抗」、V16「上苍」补画面**：两镜都要有人物或物件、要有前中后三层。例如 V14 让鬼屠从跪着的百官中站起，「反抗」被他起身的气浪掀开；V16 仰拍雷云加天幕，「上苍」被刀逼退并碎裂。V16 的「苍」至少停留 1 拍、能读清，「不」不许出画。
5. **撞副歌一的三处改掉**：
   - P15 举刀向天：改成 MS 或 CU，或者换动作，比如刀尖拖地后猛然转身，避开 S030；
   - V11「量」方印：见第 3 条；
   - P06 / S028 两个「血」巨字：P06 的「血」改成门缝里流出的血水写成的小字，或者竖排融进血幕，把朱红巨字留给 S028。

### P1
6. 人物统一调色：V08、V18 的手压成和场景同色温（冷灰加微红轮廓光）。V24、V25 剪影加冷色轮廓光和雨水溅边，人物在 V24 的占比放大到画面 1/4 以上。
