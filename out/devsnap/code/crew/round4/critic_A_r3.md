## 返工清单

### P0（不改不过线）
1. **V08（23.45–25.27）朱印层级**：「罪状」印痕必须在手和玺**下面**：顺序改为 宣纸底 → 印痕 → 玺身 → 手。24.48 落印那一拍：玺身离开纸面后上抬 20–40px，才露出印痕（印痕边缘做纸纤维晕染、不是硬边方块，朱红饱和度降 15%）。手里要看得出握着一方玉玺（深青玉或金，带钮），不能是空手按一个暗块。生不出就换成「手按玺 → 下一拍俯拍纸面印痕」两段。
2. **V17（38.07–39.47）去掉红方印「正」**：这是副歌一 S032 的标志画面，A 组不能先用。改法二选一：
   - (a) **天降巨印的侧面/底面**：只拍巨印压下来的厚重体积（玉石或青铜侧面、印钮、边缘崩口），印面朝下看不到字；38.72 落地后俯拍地面上的**凹陷印坑**，坑底是凹进去的「正」字阴影（石材，不着红，靠侧光和裂缝暖光读字）。
   - (b) 「正」字由**墨**写在雨夜石板上被巨影压住。
   不管哪种：去掉色散 glitch 碎屑（廉价 VHS 感，和本段水墨/雨夜气质不搭）；删掉印框左侧那条竖黄线；「由权势执掌」整句离开印面上沿 ≥40px 或放到画面下三分之一。
3. **V09（25.27–27.07）天平重做材质与空间**：
   - 天平要有实体：青铜或乌木横梁（有厚度、高光、刻纹），链/绳有粗细；右盘换成一方金玺（有钮、有阴影），不是平涂几何块；左盘纸人丘要读得出一个个剪纸人形（白宣 + 墨线 + 层叠投影）。
   - 背景给空间：大殿暗部 / 烛光体积光 / 地面反射，至少前中后三层。
   - 「谁把人命装进天平」：字放在梁**下方**并离开梁 ≥20px，「人命」朱红加暗衬或描边，保证缩到 480px 宽时也能读。
   - 如果预算允许，直接生一张「青铜天平特写，左盘纸人，右盘金印，暗殿烛光」作底，比代码画来得快。
4. **不重复（全段）**：红方印母题本段只留一处（建议留 V08 改好的纸面印痕，V17 按上面改掉）。片名旁的小朱印、署名小印不算。

### P1（过线后也要改，影响精致度/设计分）
5. **A07a（10.61–13.35）片名压城楼**：城楼是平涂剪影（屋顶像一块红黑色板、右侧城垛是白框矩形），左上角有一团灰黑糊块（前景旗？读不出来），「季」压在城垛/旗上、红印压在旗上，片名底下很乱。改：片名期间城楼整体压暗 40% 并虚焦，给片名留一块干净的暗区；城楼至少做出瓦垄和斗拱的明暗层次；左上前景旗要么做出布料褶皱和边光，要么删掉。
6. **V12（29.83–30.73）背景**：红色竖条纹仍然读成舞台幕布。换成被刀风劈开的雨幕 / 竹影被红光透出的纵深，至少有一层前景虚焦。恶徒头部一圈灰白发雾/毛边要收；「我杀过」小字贴着恶徒腿，挪到左下暗区（鬼屠刀下）。
7. **V13（30.73–32.57）构图空**：两人都小，中间一大块暗灰竖条，「放」悬在半空和谁都没关系。建议跪者放大到前景 MCU 虚焦、鬼屠在中景收刀，「放」字落在两人之间的地面水洼倒影里或随收刀刀光写出。
8. **V14（32.57–34.40）撞标杆**：歌词沿刀身排列和副歌一 S046（84.77–86.13「就是我的回」写在刀身上）是同一个手法。保留拔刀面部，但字的处理要换：比如字被刀身**反射**到脸上（映在眼睛下方的反光带里），或者刀出鞘时把字从鞘口「刮」出来的火星成字。至少不要整句平铺在刃面上。
9. **V16（36.23–38.07）空**：太上皇在右，左边一大团金光 + 一个「若」，画面下半全空，金光也没有形状（应是「巨印阴影成形」）。在光里做出巨印轮廓的剪影（和改后的 V17 接上），「若正义」挨着光放，不要一个字孤零零在左下。入转场 ink_bleed 的中点（36.33）是太上皇和鬼屠脸的双重曝光，两张脸糊在一起，改成以「主」字墨槽为遮罩的硬边晕开。
10. **V18（39.47–40.84）**：整帧是平的灰，人物小、读不出地面和印坑；「那我」两字在左上几乎看不见（40.18）。保留高机位大远景，但要在画面里看见 V17 的印坑（暖光裂缝）作为人物站位的引导线，歌词首字至少 120px。
11. **V15（34.44–36.27）握刀**：右手是从刀身下方托着刃，不是握柄，像捧一块木板。刀尖应该抵在碑面上（有火星/石屑），现在刀尖离碑还有一截，「我的」是飘在空中的。在 35.07 前把刀尖贴上碑面，手改成握柄或换生图。
