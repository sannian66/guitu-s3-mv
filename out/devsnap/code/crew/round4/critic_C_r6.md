## 逐项理由（只写变化部分；未变的扣分点同 r5）

- **节奏 13.5（±0）**：C21–C24 四个约 1.4s 的镜头连排，C13 1.37s 只有一个居中物体，这两处都没有动。
- **分镜 12.5（±0）**：C13、C37 仍是居中正面单物体，没有前景层；C04 左上碎纸人仍然打散视线。C03 的人偶站位比上轮好，但两处重叠让队形读不清，加减抵消。
- **精致度 13.5（+0.5）**：加分来自 C04/C05 的铸字、C26 的石块。扣分：C13 新增平面多边形碎片；C03 仍是剪贴画；C26 石块的亮描边有抠图感；C41 字芯过曝；C15 雷光是贴片。
- **歌词 13.5（+0.5）**：加分来自 C04/C05 的铸字和 C21「一方」能读了。扣分：C16「血」仍贴遮幅边；C40 的「就」提前出现；「谁的正义」的斜面浮雕略带艺术字味，离「刻在秤上、压进箱里」这种和画面的互动还差一步。
- **不重复 8.5（±0）**：C03 的克隆感减轻了，但脸模板仍相同。C09/C31/C32 的举刀母题仍在。新增的问题是转场里白闪偏多。
- **转场 9.5（±0）**：三处 hard 改好了，加分。但白闪和白光在 C13→14、C27→28、C28→29、C36→37 重复出现；glitch_cut 的数码扫描线放在古装片里出戏，加减抵消。
- **人物 8.5（±0）**：问题同 r5：C41 偏插画，C15 雷光没有勾出主角。
- **情绪 9.5（±0）**：风暴之眼的入口仍不够有分量。

### P0

### P1
1. **C13 风眼（131.67s）**：
   - 删掉左下白色、右下红色两组平面多边形碎片。
   - 黑圆改成有纵深的漩涡井：由内到外做 3 层旋臂，内层快、外层慢；中心不是纯黑，要透出暗红。
   - 用被吸入的雨线、碎云取代剩下的速度线。
   - 镜长压到 0.9–1.0s。
2. **C03 皮影（120.9s）**：
   - 做背光透色：后方暖光透过人偶，袍面半透明，叠色后加深；袍上镂空花纹透光，代替现在的圆点平涂。
   - 拆开左右两端重叠的两对人偶，间距至少半个人偶宽。
   - 至少换 2–3 种脸谱或侧脸。
3. **C41「答」（161.0s）**：字芯压回暖红；外缘保留焦黑；竹字头笔画完整；火焰只做在边缘。全段最后一个字不能是一团白黄。

### P2
4. **C26 石块（146.1s）**：去掉每块石头的均匀亮描边，改成暗面加边缘高光；石面纹理按块错开，不要同一张平铺噪声。
5. **C04 左上彩色碎纸人**：要么交代来源（从左盘倾落、被秤砸飞），要么删掉。
6. **C21–C24（139.9–145.5s）**：四个约 1.4s 的镜头里至少拆短一个或插一刀，止住副歌中段掉速。
7. **白闪同质化**：C28→C29 或 C27→C28 二选一，改成抖动或朱偏。glitch_cut 的扫描线改成纸撕或墨裂，统一古装质感。
8. **C16「血」上移**，离开遮幅边。**C40** 去掉提前出现的半透明「就」。
9. **C37「判」匾**：加前景（雨帘、近景匾框虚化），提亮匾心金字。
10. **C15 雷光**勾出主角轮廓；**C19** 加近大远小的枪头透视，不要等大放射排列。
11. **「谁的正义」**：减弱斜面浮雕的艺术字味，往「铸在秤杆上的铭文」方向靠，和秤体发生接触。
