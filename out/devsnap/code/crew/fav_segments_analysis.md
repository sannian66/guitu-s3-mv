## 3. 其他段落为什么没有这个效果

- **镜太长**：A 段平均 1.52s/镜，长镜多，靠运镜而非切点推进；副歌一 1.34s 虽有运镜但信息密度不如三段。
- **手法复用**：金色大字＋硬切＋闪白在多个段落反复出现，观众会"认出招数"。
- **收尾参数不统一**：五套 kit 的颗粒/辉光/暗角/色温各不同（见 `crew/round4` 各组 kit），段内一致、段间跳。
- **字多为屏幕层字幕**：屏幕层排版占多数，缺少"刻/印/擦/烧/穿线"这类与画面物件互动的处理。

## 4. 可执行结论（若要全片向这三段看齐）

1. 母题清单化：A 前段／B 导歌／E 终章各定单一命题，禁止跨段复用意象。
2. 镜长规范：正文 0.9–1.4s，每 8–10s 安排 1 镜 0.6–0.8s 加速。
3. 转场去重表：同段 15 镜内同一入转场不重复（D 组 §9 已是范例，可升为全片规范）。
4. 歌词道具化：剩余屏幕层字幕改为画内物件（刻／印／擦／烧／穿线／拨珠）。
5. 统一 grade：颗粒、辉光、暗角、红色纯度、色温统一成一套，段间用 LUT 匹配。
