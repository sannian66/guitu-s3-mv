# 评审 · C 段（c_pre2_chorus2，帧 3534–4839，117.8–161.3s）第三轮

评审：独立上下文，没看 C_storyboard、HANDOFF 和以往 critic_C_*。
看过的材料：out/round4/C_contact_v7_p0–p3、C_keys_v4_p0–p5、CHARTER「硬性质量要求/评审」两节、标杆 out/chorus1_v3_contact.jpg。
核查方式：用 analysis.npz 的 beats 和 align.json 的逐字时间，对 units/sec_c_pre2_chorus2.py 里的 CUT_T、CUT_F、CUTS、MOV 和精灵调用做了核对。另外单帧渲染了 6 帧：124.40 / 133.00 / 145.45 / 149.60 / 152.85 / 161.10。

## 结论：**不过线**（76.5 / 100；「精致度」10/15 低于 70%；有 2 个不可交付镜头：C06、C41）

这一版整体比副歌一以外的段落明显成熟。概念链完整（纲 → 秤 → 暗箱 → 不认 → 刀 → 风眼 → 枪林 → 邪正 → 铜墙 → 劈开 → 扛 → 量 → 刀就是我），歌词和画内物体的互动也有几处真正出彩：「劈」被一劈两半、「大局为」刻在悬牌上、「邪|正」被刀线分屏、「铁壁」做成铜牌、「判」字匾。
问题集中在三点：
1. **材质风格不统一**：写实雨夜人像、游戏 UI 式的金框发光字、扁平图标纸人混在一起，C06 和 C41 两处会直接拉低全片档次。
2. **和副歌一撞画面**：C25 墙前跃起配「那就劈开它」，几乎复刻 S035。
3. **结尾转场太平**：最高潮的最后 4 刀（C39→C40→C40b→C41）全部是 hard。

## 逐项理由

### 1. 节奏卡点 13/15
- 核对结果：43 个切点里 33 个落在 beats ±6ms 内。其余偏离拍点的都对上了人声首字：C07「我」124.90 差 +20ms，C08「不」差 +20ms，C16「刀」差 −30ms，C30「骨」差 0，C24「就」差 0，C39「量」差 +20ms。没有发现「既不在拍、也不在字」的切点。
- 视觉帧统一比声音早 2 帧（67ms）。作为风格可以接受，但 C35b（154.545，比拍点早 109ms，比「扛」154.70 早 155ms）叠加这 2 帧以后，实际切在「扛」前约 0.22s。「扛」字的冲击被提前泄掉了，扣 1 分。
- 平均镜长 1.01s，副歌段 ≤1.0s，预副歌 C02 最长 1.60s，都达标。
- MOV 表里 C05、C13 没有给运镜。C13 有风眼自转，C05 有钱币飞溅，勉强算镜内有运动。但 C05 是 0.90s 的居中正面箱子，读起来像静帧，扣 1 分。

### 2. 分镜设计 11/15
**好的地方**
- 图形匹配和同轴推进有 6 处以上：C01→C02 朱笔竖线 ↔ 红丝线，C10→C11 横刀光 ↔ 横刀身，C11→C12 同轴推进，C12→C13 亮部生出风眼，C20→C21 对角刀线变成分屏线，C26→C27 亮天 ↔ 缺口。
- C21 邪/正分屏、C35→C35b 从全身跳到咬牙中近景，都是有设计感的镜头。

**扣分**
- **C06、C37、C41、C05、C23** 都是居中、正面、单层的「物体贴脸」构图，没有前景和后景，三层景深不成立。连续几个这种镜头时，画面会像 PPT 翻页。
- **C09（126.27s）与 C32（151.70s）** 用的是同一精灵 C/slash_strings：全身、举刀过头、雨夜灰背景，景别只差一档（中全景 → 中景）、方向一左一右。观众会觉得「又一次」。
- **C17 → C18** 都是正面中全景、人物居中、身后雨幕，相邻两镜景别没有交替。
- **C29 → C30**：中景正面走来接胸腹特写，方向相同，接得还可以，但 C30 的构图问题见「精致度」。

### 3. 精致度 10/15（不达标）
- **C06「暗箱」（不可交付）**：单帧 124.40s 渲染结果如下。
  - 金色回纹框整体偏左，没有居中，也没有构图理由。
  - 框外左侧 x≈145–185、y≈95/385/430 有 3 条孤立的短横线，像故障残片或 UI 遗留，看起来就是 bug。
  - 字是游戏按钮式的外发光金字，和全段写实雨夜完全不是一个世界。这是全段最像「模板」的一镜。
- **C41「正」字权（不可交付，段落收尾）**：单帧 161.10s 渲染结果如下。
  - 周围的纸人是扁平的单色图标，轮廓和厕所指示牌一模一样，作为高潮最后一帧会让人出戏。
  - 秤砣上方的方块错位悬空，几何关系读不通。
  - 右下角的橙色弧形物体看不出是什么。
  - 对比 C03 的皮影纸人（有纸纹、有透光），C41 的同一母题明显退步。
- **C03 / C04**：纸人是平贴的剪影，秤是低多边形质感，没有体积光、没有纸张透光。和后面写实人物的段落断层明显。
- **C15（133.38s）**：人物只占画面约 8%，抠像边缘发硬，闪电是 2D 贴片，像素材拼贴。
- **C19（137.49s）**：枪头和红缨是贴片放射排列，没有透视缩放和景深虚化，像贴纸。
- **C30（149.15s）**：画面上沿正好裁在嘴部，属于 CHARTER 3 说的「人物被裁坏」。要么裁到下巴以下，要么露出完整的脸。
- **全段色差（RGB 分离）滥用**：keys 里 C33、C34、C39、C40、C40b、C28→C29 都带明显的红青描边。它本该只是冲击点缀，现在成了底噪，让画面显得脏而不是精致。副歌一几乎没有用。
- 做得好的：C11/C12 赤热刀身、C24 刀划铜墙的火花、C38 握刀的手、C35b 掌心火花、C36 雷雨军阵。这些都已经是商业级。

### 4. 歌词排版 12/15
**好的地方**
- 「劈」被斩开（145.45s 单帧，左右两半错位，红色发光），是全段最好的一处。
- 「大局为」刻在悬牌上，「邪|正」随分屏线分开，「铁壁」做成铜牌，「判」做成匾，「亮」用闪电勾边，「量」用朱红体积字。
- 关键字朱红/金的规则执行到位。

**扣分**
- **C33「对」（152.85s 单帧）**：白字压在高光刀面上，又带色差，几乎读不出来。「非」是灰色残影，读不出。
- **C04「谁的正义」、C05「成了交易的」**：字号 50–58px，挤在角落，打字机效果太小、太弱，预副歌的权力感出不来。
- **C34「是非对错」**：「是」「对」被画面左缘裁掉一部分，并且有动态模糊。和副歌一 S040 的「是非对错」纸面大字相比，这一版反而更乱。
- **C40「这一」**：压在人物衣摆上；「刀就」是灰色半透明，压在秤杆上读不清。
- **C06「暗箱」**：UI 发光字的问题见上。

### 5. 不重复 7/10（压线）
- 精灵次数合规：S062/puppeteer 用在 C02、C31；C/slash_strings 用在 C09、C32；S082/walk_front 用在 C27、C29；C5/c16_drip 用在 C16、C33；C/blade_hot 用在 C11、C12。都是 2 次。
- **和副歌一撞画面**：
  - **C25（144.82s）** 人物在刻字砖墙前跃起持刀，配「那就劈开它」，和标杆 S035（69.63s，同一句歌词、同一砖墙、同一跃起）几乎一样。
  - **C16** 红色「血」大字 ≈ S028。
  - **C34**「是非对错」 ≈ S040。
  - 歌词重复可以呼应，但 C25 是同构复刻，必须改。
- **段内重复**：
  - 秤 / 「正」字权出现在 C04、C40、C41，以及 C40b→C41 的转场帧，作为首尾母题可以，但 C41 又把 C04 的纸人搬了回来。
  - 士兵出现两次：C18 冲锋的士兵和 C36 军阵。
  - C09 和 C32 同构（见上）。

### 6. 转场 8/10
- 用到的转场类型足够：match_line、whip、glitch_cut、push、seam、slash_wipe、luma、over、occlusion、ink_bleed、shatter、split_slide、flash_red，共 13 种以上，远超 5 种。
- 扣分：
  - **结尾 C38→C39→C40→C40b→C41 连续 4 个 hard**，**C32→C33→C34→C35→C35b 连续 4 个 hard**。最后的高潮恰恰是转场设计最少的地方，只靠 2 帧推近提亮撑着，冲击的花样单一。
  - push 用了 6 次、slash_wipe 用了 3 次，有点依赖。
  - C40（刀斩天平）→ C40b 本来天然适合用斩切或匹配剪辑，结果给了 hard，浪费了。

### 7. 人物 7.5/10（压线）
- 表演和歌词对应得好：「扛」双手托刀，「量」蓄力，「刀就是我」刀尖指镜头，「我不低头」抬下巴，「不认」怒目。
- 扣分：
  - **定妆脸不统一**：C35b（154.47s）有刘海、显年轻、表情接近龇牙笑，和 C07/C28 的长脸冷峻像两个人。C29 的脸型也偏。
  - **光色**：C28 的橙光脸和冷雨主光冲突，是有意为之，但没有可见的光源交代。
  - C15、C27 人物太小，读不出是主角。
  - C30 裁坏（见上）。

### 8. 情绪叙事 8/10
- 位置正确：从雨夜过渡到风暴之眼，C13/C14 风眼、C36 雷雨军阵把「风暴」立住了。
- 叙事线清楚：权力的工具（纲 / 秤 / 暗箱）→ 拒绝 → 风暴 → 破墙 → 扛 → 自证。
- 扣分：收尾 C41 落在一个廉价的金秤砣上，副歌二的最高点（「这一刀就是我的回答」）情绪被泄掉。C40b 的发光眼比 C41 更适合当终点。

## 返工清单

### P0（不改不过线）
1. **C06 重做**：去掉框外 3 条残片短横线，取消游戏 UI 式发光字。建议做成「暗箱」两字烙在箱盖内壁上：箱盖缝透出金光，字随箱盖合上被压进黑暗，有纸面或金属质感，构图居中或有明确偏置理由，加前景箱沿。
2. **C41 重做**：去掉图标式纸人，或者换成 C03 那种有纸纹、透光的皮影纸人，并让它们散落或燃烧；修好秤砣顶块的几何；去掉含义不明的橙色弧形物。更好的方案是把落点交给人物或刀，例如 C40b 的刀光一路扫成「答」字烧穿画面，「正」字权只在背景里坠落碎裂。
3. **C25 换掉副歌一 S035 的同构**：同一句「那就劈开它」不能再用「墙前跃起」。建议改成刀刃特写从下往上斩、俯拍砸墙，或者让墙从画面中轴被纵向劈开，人物出现在裂缝里。总之换景别、换方向、换处理。
4. **全局压色差**：RGB 分离只保留在 C04 glitch_cut 和 INSERTS 的闪切帧上，其余镜头（C28–C34、C39–C40b）关掉或降到 1px 以下。这是「精致度」回到 ≥11 的最快一步。

### P1
5. **C33「对」改可读**：字放到刀身暗部，或者改成刀身反光里的镂空字（暗字亮边）；「非」至少要读得出。
6. **C30 重裁**：上沿裁到下巴以下（纯胸腹），或者露全脸。不要裁在嘴上。
7. **C35b 换定妆脸**：和 C07、C28 统一（无刘海、长脸、冷峻），咬牙而不是咧嘴。
8. **结尾转场**：C40→C40b 用刀光斩切（slash 方向和刀一致）；C40b→C41 用 iris 或 zoom_through 穿过刀尖光点；C33→C34 可以用 match_cut（刀线 → 刀线）。保证最后 6 刀里至少 3 种有设计的转场。
9. **C09 / C32 去同构**：C32 改成低角度仰拍或背身剪影，或者换成 C/slash_diag_down 的变体。
10. **C04 / C05 字号加大到 ≥80px**，打字机的光标闪烁加上金属冲压感，并占据画面视线中心，不要缩在角落。

### P2
11. C34「是非对错」：四个字完整入画、不被裁，和副歌一的纸面大字拉开处理，例如刻在四面飞旋的刀身上。
12. C15 人物放大到画面 25% 以上，闪电改成体积光，并照亮人物轮廓。
13. C19 的枪头加透视缩放，近大远小，近处的枪头加景深虚化。
14. C35b 切点往后挪约 3 帧，贴住「扛」154.70。
15. C05 加缓推和前景钱币虚焦，不要正面静置。
16. C40「刀就」改为实色，不要用灰色半透明；「这一」挪出人物衣摆。
