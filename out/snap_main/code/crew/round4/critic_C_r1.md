## 各项理由

### 节奏卡点 12/15
- 41 镜 / 43.5s，平均 1.06s，0.47–1.60s。副歌的切分密度够了，不再是基线的慢节奏。
- 切点和音频拍点（约 129 BPM）比：中位偏差约 45ms，起音偏差中位约 39ms，可以算卡上。偏离起音超过 80ms 的切点有 6 个：118.9s（C01→C02，约 200ms）、128.7s（C09→C10）、134.45s（C15→C16）、135.5s（C16→C17）、148.5s（C28→C29）、149.3s（C29→C30）。这里的切点是按中点 − 时长/2 推算的，本身有 ±30ms 误差，需按真实切帧复核。
- 扣分点：预副歌（C01–C06，平均约 1.17s）和副歌（约 1.0s）的切速几乎一样，进副歌（≈125.2s，C07）没有加速或"顿一拍再炸"的层次，副歌二对副歌一也没有加码。中点帧里大量镜头是"静态构图 + 雨"，镜内运动是否卡点从静帧无法确认，按风险扣分。

### 分镜设计 10/15
- 有设计的镜头：C01 律令卷轴、C03 纲 + 提线纸人、C04 / C40 天平首尾呼应、C10 字牌"大局为上"、C21 邪 / 正对劈分屏、C22–C26 "律令墙 → 铁壁 → 劈开 → 碎字砖"一条线、C33–C34 是非 / 对错字碑、C35 我自己扛（红色压顶）、C38 手指抹刃。这条视觉论证是成立的。
- 扣分：
  - "雨夜远景中间站一个小人"的模板化构图反复出现：C14、C15、C29、C31、C32，加上 C17 也接近，景别、机位、构图几乎相同，没有设计感。
  - C13 白色放射爆点是通用占位特效，和歌词"还在发烫"没有画面关系。
  - C28"亮"是满屏白底加金字的字卡，副歌二高潮字落成平面字卡，分镜上最弱。
  - C19"谁人来"用提线 / 兵俑表达，思路可以，但执行是简陋的。

### 精致度 9/15
- AI 角色立绘镜头（C07、C08、C09、C20、C21、C30、C38、C39）质感够商业水准。
- 程序化道具和场景明显掉档，同一段里两种完成度割裂：
  - **C19（4137）**：兵俑是圆头圆身的白模级几何体，像未贴图的占位资产。
  - **C36（4673）**：军阵是一团团黑色团块，红旗是平面贴片，远看像噪点。
  - **C06（3728）**：金色矩形框加满屏故障条纹，"暗"字被故障切出一块方形缺口，读成"暗▪相"，像渲染错误。
  - C05 宝箱、C23 铁 / 壁的半透明"盒子"像线框调试框，没有材质。
  - C16"血"是平涂红加外发光，没有材质和体积，和副歌一的"血"同一招，而且更素。
  - 转场中间帧多为灰雾或灰色拖影（C23→C24、C39→C40 是空的灰横条，C13→C14 的 3968 帧是一团脏烟，没有主体）。

### 歌词排版 10/15
- 版式有变化，比基线强：竖排、巨字压画、字牌、刻砖、立体字碑、红黑双色强调字。
- 执行问题多，而且是交付级错误：
  - **贴边 / 被裁**：C08"不认命"的"命"被下沿切掉；C12"还在发烫"只剩"还在"加半个红字；C27"看个天"贴着画框下沿；C41"答"被切掉半个。字幕安全区没有守住。
  - **残字**：C20 只露出"宀"（"定"被裁），观众读不出字。
  - **不可读**：C36"天不"中的"天"压在军阵上，灰对灰几乎看不见；C37"判"下面的小字（"天不……"）被雾吃掉。
  - **故障损字**：C06"暗相"、4398 帧（C26→C27）的"看个"后面跟着一串碎字残片，像出错。
  - 同一句歌词跨镜接续时，字号和位置跳得太随意（C31"骨未" → C32"是" → C33"是对错"），没有一套贯穿的版式规则。

### 不重复 6/10
- 色调：约 30 镜都是"灰黑加斜雨"，只有 C01–C06 的暖金和 C35 的红跳出来。
- 母题重复：环形光圈（C17、C31）、军阵（C18、C36）、雨中远景小人（C14、C15、C29、C31、C32）、斜劈光线（C09、C21、C25、C34）。天平（C04 / C40）算有意呼应，不扣分。
- 和副歌一相比，"血""墙""是非""天"的处理是同一套路的写实翻版，副歌二没有给出新的视觉母题。

### 转场 6/10
- 每个切点都标了转场类型（match_line、whip、glitch、zoom_through、slash、shatter、occlusion），数量上解决了"转场也没有"。
- 质量不够：
  - 已换掉 4 处白闪，但 keys 表里仍有 6 处 flash_white 加 C28 白底字卡，换掉 4 处后估计还剩约 2 处白闪，加上 C13 白爆点和 C28，白场依然过多。
  - whip_pan_blur 的中间帧只是一层灰色横向拖影，没有前后两镜的内容（C23→C24、C31→C32、C39→C40）。
  - zoom_through 的中间帧大多是灰雾（C04→C05、C22→C23）。
  - 换掉白闪的替代转场帧本身也很弱：3968 是脏烟，4398 是黑场加碎字。
  - 真正漂亮的只有 C01→C02 红线 match_line、C25→C26 碎砖 shatter、C20→C21 斜劈。

### 人物 7/10
- 主角立绘（C07 侧脸、C08 特写、C39 持刀）一致性好、质感在线，C20 / C21 的对手形象也有气势。
- 但主角在 41 镜里只有约 6 镜是有表演的中近景，其余大量是远景小剪影（C14、C15、C29、C31、C32），没有动作设计和情绪表演。副歌二"我自己扛""刀就是我"本应是人物最强的表演段，C35 和 C40 仍是站桩构图。

### 情绪叙事 7/10
- 叙事线清楚："规则 / 交易"（纸人、律令、天平、宝箱）→ 不低头 → 律令墙 → 劈开 → 我自己扛 → 刀就是我（天平呼应）→ 回答（光环）。立意成立。
- 高潮落点弱：C28"亮"用白卡，C36"天不"糊成一片，C41 收尾的光环纸人和 C17 / C31 的光圈形成语义重复。副歌二对副歌一没有情绪加码。

## 不可交付镜头清单

1. **C19（137.45–138.35s，约帧 4123–4150）**：兵俑为白模级几何体，成片里不能出现。
2. **C36（155.32–156.22s，约帧 4660–4687）**：军阵是团块噪点，"天"字不可读。
3. **C06（123.7–124.83s，约帧 3711–3745）**：故障把"暗"字切出方块缺口，金框粗糙，观感像渲染错误。
4. **C26→C27 切点（约 146.5–146.7s，帧 4395–4400）**：黑场加碎字残片，"看个天"被打碎成乱码。

边缘镜头（下一轮不改即列入）：C13 白爆点占位、C28 白底"亮"字卡、C20"宀"残字、C08 / C12 / C27 / C41 歌词被裁。

## 返工意见（按优先级）

1. **【P0】重做 C19、C36（138s、156s）的兵俑和军阵**：要么用和主角同级的 AI 立绘或贴图军阵（剪影要有盔缨、甲片轮廓，加大气透视和雨幕分层），要么改成不依赖人群资产的构图，比如大面积旗海剪影或地面矛影。C36 的"天不"需要独立底板（暗角加局部提亮），字要能读。
2. **【P0】全段做字幕安全区排查**：C08"命"、C12"发烫"、C20"定"、C27"看个天"、C41"答"，任何字不得被画框或遮幅裁切，残字必须修。C06"暗相"的故障只能作用于背景或字的边缘，不能切掉笔画。4398 帧的碎字残片要去掉，或者改成可读的碎字动画（字先完整出现，再碎）。
3. **【P0】转场返工**：
   - 剩余白闪全部换掉（C06→C07、C35→C36 等），C28"亮"不要用满屏白卡，改成光从 C27 墙缝中真实炸开、照亮主角。
   - whip_pan_blur 的中间帧必须带前后镜内容的方向性拖影，不能是空灰条（C23→C24、C31→C32、C39→C40）。
   - 3968（C13→C14）的脏烟替换掉，改成热刃蒸汽、雨幕之类有主体的过渡。
4. **【P1】拆掉"雨夜远景小人"模板（C14、C15、C29、C31、C32）**：至少换掉 3 镜，用低机位仰拍、前景刀 / 雨滴大虚化、过肩、俯拍顶视、局部特写（脚踏水、握刀手、发梢甩雨）打破同一机位。C17 / C31 的环形光圈只保留一处。
5. **【P1】进副歌（125.2s，C07）和副歌二后半（≈148s 起）做节奏层次**：进副歌前留 2–4 帧的"吸气"（压暗或停帧），副歌后半切速提到 0.6–0.8s，并加镜内推拉和抖动的卡点。复核偏差较大的切点：118.9s（C01→C02）、128.7s（C09→C10）、134.45s（C15→C16）、135.5s（C16→C17）、148.5s（C28→C29）、149.3s（C29→C30）。
6. **【P1】提升道具材质**：C05 宝箱、C23 铁 / 壁（去掉线框盒感，改成真实砖块凸起加碎屑）、C16"血"（加湿润材质、流淌，或刻进刀身和地面，不要平涂发光字）、C06 金框（加纹饰、厚度和光影）。
7. **【P2】人物表演**：C35"我自己扛"、C40"刀就是我"改成中近景加动作（举刀定格、回头、刀尖指镜头），C39 → C40 → C41 的收尾三镜至少有一镜是主角面部情绪特写。
8. **【P2】色彩和母题**：副歌二加一种副歌一没有的视觉母题，或一段色彩反转（例如 C33–C35 段整体转为红黑），打破约 30 镜的灰雨同质感。
9. **【P2】歌词版式统一规则**：同一句跨镜时，保留字号和基线的连续性（C31→C33、C37→C38），强调字的红色只给关键词（血、刀、错、扛、答），不要每镜都上。
